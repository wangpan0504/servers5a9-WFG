# PVF 目录

将自行准备的匹配 `Script.pvf` 放在此目录。固定运行布局为服务端程序旁的 `Data/Pvf/Script.pvf`，与 S4A21 的目录约定一致。

从源码构建时，本目录的说明和 `Script.pvf` 会复制到构建及发布输出；数据库、日志和其他运行数据不随构建复制。仓库不提供或提交 PVF。

账号和全部游戏数据保存在同一运行目录的 `Data/game.db`。首次启动使用完整 `game_schema.sql`，单文件包使用内置 SQL，目录包同时保留程序旁的 `Sqlite/game_schema.sql`；已有库统一检查基线与版本，规则见[数据库](../../../../Docs/开发/数据库.md)。不分发种子库。完整路径及启动参数见[环境与配置](../../../../Docs/开发/环境与配置.md)。
