# S5A9 阿拉德谋略战：诺兰入口 PVF 修复包

本目录可整体压缩并交给其他agent。适用客户端为S5A9 / V31.0.24.0，已验证诺兰可见并能打开谋略战。修复使用接收方自己的原版PVF，不依赖发送方的仓库、服务端DLL、磁盘路径或PVF副本。包内不含游戏资源。

## 交给接手agent的任务

在目标机器查明实际使用的客户端与服务端PVF路径。优先用接收方保留的原版PVF，按下述两处修改生成新封包；检查修改结果后，再同步到实际使用的两端。客户端需完全退出后替换并重新启动；正在使用PVF的服务端正常停止后替换，并按原参数启动。服务端运行目录、数据库和启动参数以接收方现场为准。

只修改以下两份包内文件。不要修改XUI、NPC定义、EVT、日期、怪物、卡片、奖励或任务完成记录。若输入曾被修改，先恢复为接收方自己的原版资源；本脚本仅处理这两处，不负责恢复其他既有修改。

### 1. 房间使用原版107

文件：`map/common/(r)gate_seria.map`，区段：`[NPC]`至`[/NPC]`。

原版同位置有两个引用：

```text
400001107 `[right]` 608 168 0
400001112 `[right]` 608 168 0
```

保留107，删除112对应的完整五个token：

```text
400001107 `[right]` 608 168 0
```

其他NPC及地图内容保持原样。若已经只有107，无需重复修改；若107缺失或两者位置不同，先核对目标版本，不直接套用删除。

### 2. 取消107隐藏

文件：`etc/hiddennpc.etc`，区段：`[hidden npc]`至`[/hidden npc]`。

只删除其中的整数`400001107`，其他整数、区段及`[npc visibility quest sequence]`中的6356、5961均保留。已无该整数时无需再次修改。

107在原版隐藏名单中，单改房间引用会导致诺兰不显示。原版112不在名单中，但只有商店菜单。107的原版定义`npc/chn_monstercolosseum_nolan.npc`已经包含商店400000097、`[open monster mock battle] 1094`和`[open visible event] 2532`，直接使用即可。没有证据表明官方XUI有错。

## 独立脚本方式

需要Windows、PowerShell 7，以及已运行并开启WebApi的pvfUtility。无需安装.NET SDK、Python、Git或加载服务端源码。pvfUtility负责封包读写，脚本仅通过本地HTTP读取、导入这两份文件并另存。

1. 在pvfUtility中加载接收方自己的目标PVF，确认没有未保存的无关编辑，开启WebApi，默认端口27000。
2. 在本目录运行预览：

   ```powershell
   pwsh -NoProfile -File ./Repair-Pvf.ps1
   ```

3. 核对显示的源PVF路径，在当前目录另存为新文件，例如：

   ```powershell
   pwsh -NoProfile -File ./Repair-Pvf.ps1 -Apply -OutputPvf (Join-Path (Get-Location) 'Script-nolan-fixed.pvf')
   ```

   输出目录由接收方按实际环境选择，不依赖发送方文件。WebApi端口不同则追加`-ApiBase 'http://127.0.0.1:实际端口'`。脚本拒绝覆盖源文件及已有输出，执行后读回核对两份文本的token。

4. 将生成的同一封包同步至实际使用的客户端与服务端，重新启动后验证。没有pvfUtility API时，可在支持该PVF格式的编辑器内按上述两处手工操作并另存。

脚本预览不会修改封包；`-Apply`会修改pvfUtility当前内存中的封包，再调用另存接口。若导入失败，先在工具中重载原文件，再检查原因；源磁盘文件仍保留。重复执行时两项删除数均应为0。

## 服务端与验收

服务端需已实现谋略战，并开启活动管理2532；当前实现未配置或auto默认开启，显式off会保留关闭状态。本包不实现服务端玩法，也不修改数据库存档。

验收：赛丽亚房间能看到诺兰；点击同时有商店和谋略战入口；可打开原生活动面板；活动2532关闭、开启时NPC与玩法准入随之变化。客户端和服务端使用同一份输出PVF，其他NPC仍正常。

首次100金币、30体力、召唤券数量刷新及获得画面的星级由配套服务端处理。原版特殊关日历保持原样，服务端日期映射不会修改客户端日历。这些内容不通过修改本包范围之外的PVF资源实现。
