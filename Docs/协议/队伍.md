# 队伍协议

记录匹配 S5A9 客户端的城镇组队及 J 面板合同，业务与限制见[队伍](../模块/队伍.md)。S4A21只能参考业务顺序，不能照搬 opcode、固定设置块或成员宽度。

## 设置及名册

CMD12基础请求15B：`operation:u8 titleCode:u8 [title:DSTR/CP936] capacity:u8 dungeon:u32 difficulty:u8 argument:u16 flag:u8 kind:u8 kindArgument:u16 option:u8`。titleCode=0才有名称，最多63字节，对应接收侧64B缓冲。普通请求必须完整消费；operation1/kind1的原生快捷改名允许省略末尾 option，沿用原设置。实收创建`00 04 04 00000000 05 0000 00 00 0000 07`不能截成 S4 的14B。

设置成功发送完整 NOTI9，不以通用 ACK12代替。失败`00 error:u16`，设置拒绝使用本版已确认分支21。NOTI9接收入口023B9E70，头为`count:u16 pageCount:u16`；普通名册 pageCount=9999，目录为实际总页数。记录前缀`partyId:u16 server:u8 channel:u8 reserved:u8 action:u8 flag:u8`。action0完整模型，action3删除且不跟设置/成员段。

完整设置段：`u8 titleCode:u8 [DSTR] u8 capacity:u8 reserved:u32 difficulty:u8 argument:u16 flag:u8 kind:u8 kindArgument:u16 reserved:4B dungeon:u32 reserved:2B option:u8`。目标副本写后部u32（模型+116），不写前部同宽零字段。未确认标记保持零，不解释成资格或权益。

成员段`count:u8`后逐个`slot:u8 actor:u16 reserved:5B`，只发本 server/channel，不进入跨服附加角色块分支。随后额外成员记录数0、八个u8尾部（第二字节为真实队长槽）、附加结构选择器0。无自定义名称的单成员完整通知56B，删除11B。客户端保留八槽域，本服实际槽位0–3。

## 邀请、回应及端点

CMD10/mode0邀请13B：`target:u16 mode:u8 peer:u32 reserved:6B`，成功ACK10=`01`。目标先收Actor，再收NOTI7：`source:u16 mode:u8 peer:u32 reserved:10B`。CMD11接受7B，拒绝在7B后附`85 00`；peer为回应者自身连接数据，不要求回显邀请值。接受ACK11=`01 source:u16 mode:u8`；发起方收到目标Actor和7B NOTI8。失败`00 error:u16 mode:u8`，拒绝通知 error133。mode15归[玩家交互](玩家交互.md)，mode1直接交易未接入本批。

CMD13退队正文为空，CMD14踢人为`slot:u8`。成功ACK=`01`，失败`00 error:u16`；实际名册变更仍由NOTI9完整/删除记录完成。

CMD2报告15B头`nat:u8 inner:u32 outer:u32 port:u16 mtu:u32`，可跟`length:u32 marker:lengthB`。标识不用于寻址，不记录完整值；严格检查长度、单播地址、非零端口和256–65507的MTU。NOTI11为`count:u8`加每项22B：`actor:u16 inner:u32 outer:u32 port:网络序u16 account:u32 nat:u8 mtu:u32 percent:u8`。account取当前NativeChannel注册token，端点只包含实际报告者。

NOTI153为`count:u8`及每项`actor:u16 hpPercent:u8 reserved:u8 slot:u8`。023CE4B0写Data+35C，025FD5A4读取城镇血条及无战斗实体时蓝条，城镇使用100%。NOTI26为主机槽u8。完整名册之后再次发送NOTI11/153/26，把状态安装到最终成员对象。

## J 队伍目录

CMD1404/type1严格58B：18B路由头加40B查询。当前角色在偏移15的u16，页码偏移18，sort20、reverse21、sameChannel22、recruiting23、kind24、options25，关键词为偏移26的32B零结尾CP936。布尔只接受0/1，拒绝截断、无终止符、非法编码和额外尾部。只允许本连接当前城镇角色查询。

01463630/014D5D10发送查询，014636B0重置本地页槽，01463B54按包内顺序绘制三页缓存。NOTI9头`rows:u16 totalPages:u16`再跟完整记录，从page*10起最多30条，总页数ceil(total/10)。无结果回`00000000`；超页但总数非零仍回真实页数。普通频道无队伍时实收kind6需匹配kind0普通队伍。具体筛选支持边界见模块文档。

主动查询发现同频道异区队伍前只补公开Actor，不发城镇坐标/入场；被动名册仍限同场景。来源失效、选角或场景发送epoch变化、被新请求取代时旧目录结果不发布。
