# 冒险团协议

目标为匹配x86 ARAD.exe。业务与库表见[冒险团](../模块/冒险团.md)；不借用Go旧版RAW7420或旧通知号。

## 请求与包序

C2S1403正文为target:u16，小端，固定2B；ACK为success:u8，失败追加error:u16。选角期target0读取本账号；入城后0或本人UID读取当前账号。成功前缀之后与NOTI1343信息相同，失败使用已确认中立错误3，不返回伪成功。

C2S645空正文，成功ACK645为`01 00`；`02343B30`成功分支继续读隐藏角色count。当前没有隐藏角色，随后1343以actor0初始化账号。不能在名册前后未经客户端上下文准备盲发，也不能向空Actor发送1349。

`01034220`是1343消费者，`01036DD0`为1403成功入口。信息读取actor:u16、创建日期:u32（YYYYMMDD）、四个u8玩法初值、一个u32上下文初值、长度前缀RAW及CP936名称。RAW长度7440；`0102F3A0/0102EB10`构造固定角色记录，`01034386..010343AA`允许查询对象与当前对象均为空，`01034C4B → 03B58C80`更新选角名称和等级。

NOTI1375 `REPRESENT_ACCOUNT_NAME`在`023CDB34..023CDB42`注册到`023B4C30`。正文为字节长度u32、CP936账号名称及尾标志u8，名称上限16字符/32B。`023B4C59..023B4C70`先以17个宽字符的目标容量转换名称，再读取标志；非空名称经`023B4CBE..023B4CD0 → 00AEB750/01031370`分别更新登录账号对象的`+3C`名称及冒险团名称上下文，尾标志经`0102EA40`保存。当前尾标志固定0；未消费首次资格时发送空名，由`023B4C92..023B4C9F`打开1498起名窗口，其余发送持久名。选角645和入城初始化均按1375、1343、可选1349的顺序发送，1403普通查询不重置账号名称上下文。

头顶绘制不直接使用上述账号对象。NOTI2 subtype0的5B记录头之后为116B RAW；RAW偏移51至67是17B、NUL终止的CP936昵称，而非UTF-16数组。`0267E1EC/0267E220 → 03C78340`转换该字段，并安装到临时及实际角色DTO的`+460h`（1120）字符串；匹配运行构建的转换CodePage为936。`02AAB56D..02AAB5C0`复制同一DTO字符串并交头顶绘制分支，空字段不会因为1375已有名称而自动补齐。Actor刷新使用相同字段，保留原显示开关与其他RAW字段。昵称最多16个编码字节，超长只投影不拆字符的前缀；完整名称仍由1375/1343承载。

## 名称请求

1438和1444均为CP936字节长度u32及名称；发送者`00D767EF..00D76819`、`00D7773E..00D77768`均调用`03BDF8E0`。ACK1438在`0237D1CC..0237D1DA`注册到`02369420`，ACK1444在`0237D23E..0237D24C`注册到`02351830`。两者成功均为`01`及长度前缀名称；1444成功打开1499名称确认窗口，不能只回`01`。失败为`00`加error:u16，本服使用3作非法名称/资格拒绝、20作重名，不猜填其他版本错误。

1445正文为长度前缀名称、slot:u16、mode:u16。`012BAED9..012BAF3D`的道具分支写真实槽及mode0；`012BAF40`的另一分支写255及mode1。服务端保留两个完整u16，不将低8位或客户端模式直接视为付费资格。ACK注册`0237D251..0237D25F → 023519B0`；成功为`01`，失败加u16，回调成功分支不消费额外名称或库存。本服拒绝使用无效券/场景、重名及未授予的免费模式，不伪造成功。

改名成功按ACK1445、源槽NOTI1681、NOTI1375、ACK7、NOTI2名册发布。ACK7既有`02348C70`成功分支只检查成功标志便清理游戏上下文并返回选角，不依赖另一个请求正文；服务端同步经原ReturnToRoster/SetState解除角色和场景，再按原名册映射重新选角，不保留已失效的Town状态。首次命名和重名检查不切user状态。

`012BC042 → 03DDC8F0(index=0x4D77)`是改名窗口文字；13284/13285/13286在`02E35C15`、`0258BBB8`和`02E2E646`分别用于冒险团密语目标拼接及离线提示，不是1375包体或头顶Actor字段的宽度依据。名称索引查询和密语上下文是不同业务，不能以静态文案代替已实现请求。

## 代表请求

1476正文为job:u8、packedGrow:u8，1478相同；packedGrow保留0x20二觉阶段及低四位职业，不能把普通grow直接当二觉。1477正文为region:u8、角色UID:u32、job:u8、packedGrow:u8，固定7B。资格与真实UID按本账号名册复验，不按UI索引查characters.slot。

1476成功为success:u8、groupCount:u8，各组region:u8/count:u8，随后每候选52B。候选region在0、熟练u32在4、等级u32在8、UIDu32在12、CP936名char[30]在20；`010324D0`反汇编固定复制0x34B后才在客户端扩成56B，网络不发送56B。

1477成功在success后为u32长度3与type:u8/count:u16，再u32长度52及一条收藏记录。收藏布局与候选不同：job/grow在0/1、熟练在4、名称在12、region在42、等级在48。`01034DC0`读取两个独立RAW，不能只发职业计数。1478成功仅`01`，消费者`0102E8C0 → 00DB6090`清除当前选择等待。失败保持公共u16宽度，未闭合错误使用中立3；227的远征忙碌语义只随真实远征业务使用。

设置/解除先同事务保存，再ACK，随后从本次提交的快照发送1345及1343/1349。显式解除在收藏表保留职业空格、等级0，不回退为自动第一候选；远征中的代表失败错误227，不重建本人Actor或切场景。

## 远征请求与通知

441正文为areaCount:u8及各area:u8，长度严格匹配且不能重复；当前回复完整地区表，含area0空闲组。442为area:u8、durationSeconds:u32、memberCount:u16，随后每成员selector:u8/job:u8/grow:u8；`01110D20`生产固定7B头和3B成员，不能复制旧佣兵服务的另一种角色索引。

`01110D20`在成员数为0时仍发送7B正文；因此0是结构合法的空选择，交业务层拒绝，合法地区/时长下ACK442为`00 16 00`。`01110EB0`包含错误22分支，并清理等待状态、重新查询441；服务端不能抛包结构异常而断开连接。成员数量仍有4人上限，Parser严格核对完整行宽，不吞截断或追加字节。

1407取消与1408领取正文均为area:u8。442/1407成功ACK为`01`，失败追加error:u16；1408成功为`01`加reward:u32，`01111350`消费该结晶数。未到期/不存在远征使用中立错误3；无地区/等级、已运行、无时长、成员不匹配分别采用已核验7/14/18/22。未知1409请求不注册、不返回通用成功。

ACK441与NOTI1345共用success:u8后areaCount:u8表。每地区为area:u8/state:u8/start:u32/end:u32/attributeCount:u8及属性字节，再memberCount:u16；每成员为selector:u16、CP936长度字符串、level:u32/job:u8/grow:u8/status:u8。`01111FA0`按上述宽度创建远征视图；state0为空闲，1为运行，2为可领取。属性字节使用资源`[attribute data]`声明的线上ID（本版1至23）；资源里的组别名255只用于服务端展开组内候选，不写入ACK441/1345。多个地区可同时处于state1，各自携带出发时冻结的属性与成员；运行地区用冻结成员，area0只列未被占用的当前代表。

奖励公式由`0421F0F0`确认：资源地区时长倍率、人数倍率与匹配属性倍率相乘，以float32先加0.5取整，再乘extra rate取整；extra rate不再作为额外一份奖励。出发/取消/领取先提交，再专用ACK及1345；取消与领取再1343/1349刷新账号余额，不以窗口关闭代替保存。

## 商店请求

1414正文为category:u8、selection:u32，固定5B。`0102E570`反汇编调用1B写入`03BDF720`及4B写入`03BDF780`；不能因反编译将参数误标char而截断第二字段。类别内原序号和物品ID均解析到同一资源商品，回放购买表保存真实物品ID，不保存UI下标。

成功ACK为`01`，失败为`00`加error:u16；`0102ECB0`成功清理商店等待状态，19/22/204/235分别表示限购、结晶不足、容量不足及冒险团等级不足。先完成原子购买，再ACK、现有NOTI14资产差量及1343/1349账号同步；失败不发获得通知或更新限购。

## 每周地下城信息请求

789正文为server:u8，固定1B；客户端打开面板后立即发送，未获应答时持续重发。NOTI718为server:u8、count:u8，每行u32角色UID、u32名称长度、CP936名称及尾u8 0，名称上限29B，超长按完整字符截断、不拆双字节字符。名册按本账号角色槽位和UID排序；90CN同源消费者按该布局读取，本版客户端消费者待实机验证。

791正文固定5B，每字节为一个槽位的地下城ID，`0xFF`表示该列未选择；服务端按客户端提交的原字节保存，不重排、不补位。成功ACK为`01`，失败为`00`加error:u16；未就绪角色使用中立错误3，4字节等结构错误在Parser边界关闭连接。保存后不发送配置回显，客户端收到ACK即停止重发。

790、719、720、721在本版客户端未观察到发送；这些方向不注册、不返回通用成功，也不伪造周次数、重置回执或配置通知。待实机抓包确认后再接入。
