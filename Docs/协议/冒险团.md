# 冒险团基础信息协议

目标为匹配x86 ARAD.exe。业务与库表见[冒险团](../模块/冒险团.md)；只接本版基础信息，不借用Go旧版RAW7420或旧通知号。

## 请求与包序

C2S1403正文为target:u16，小端，固定2B；ACK为success:u8，失败追加error:u16。选角期target0读取本账号；入城后0或本人UID读取当前账号。成功前缀之后与NOTI1343信息相同，失败使用已确认中立错误3，不返回伪成功。

C2S645空正文，成功ACK645为`01 00`；`02343B30`成功分支继续读隐藏角色count。当前没有隐藏角色，随后1343以actor0初始化账号。不能在名册前后未经客户端上下文准备盲发，也不能向空Actor发送1349。

`01034220`是1343消费者，`01036DD0`为1403成功入口。信息读取actor:u16、创建日期:u32（YYYYMMDD）、四个u8玩法初值、一个u32上下文初值、长度前缀RAW及CP936名称。RAW长度7440；`0102F3A0/0102EB10`构造固定角色记录，`01034386..010343AA`允许查询对象与当前对象均为空，`01034C4B → 03B58C80`更新选角名称和等级。

## 固定布局

| RAW偏移 | 类型与内容 |
|---|---|
| 0 | 冒险团等级u32 |
| 8 | 当前等级进度u64，不除10 |
| 68 | 本账号角色数量u16 |
| 72 | 100条52B收藏记录；job/grow在0/1，熟练u32在4，CP936名char[30]在12，region在42，level:u32在48 |
| 5272 | 五条8B结晶数量/进度记录 |

名称为字节长度u32加CP936内容，最多16字符/32B，不能按UTF8长度编码。创建日期按账号持久值回放，查询不重新取日期覆盖存档。100条收藏记录使用当前合法默认候选，不伪造未实现的代表设置结果。

NOTI1349由`0102F910`消费：actor:u16、RAW长度u32=40、40B RAW及四个u8玩法初值。RAW等级在0、经验u64在8、胶囊u64在24、领取次数u32在32；调用`02B644B0`安装Actor冒险团等级。入城实体信息使用1343后1349，选角仅1343。未知玩法字段保留构造初值，不把四维重复加进89B角色基础属性。

旧角色配对、代表取放、远征、商店、胶囊领取及名称修改不属于本页已实现入口；对应opcode仍由所属模块核验后接入。静态消费者、独立字节读取及TCP分别验证字段和发布，不能据此声称真实窗口已验收。
