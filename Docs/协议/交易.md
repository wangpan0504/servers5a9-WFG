# 交易协议

适用于 S5A9 匹配客户端。交易与组队共享邀请命令，按完整包形态分流。

- `CMD10`：11 字节 `target:u16, type:u8=1, token:u32, reserved:4B`；`NOTI7` 转发邀请角色、类型、原 token 与当前秒。
- `CMD11`：7 字节接受，关联原邀请后向邀请者发送 `NOTI8`，其中 token 使用邀请方的原值；9 字节且尾部为 `85 00` 表示拒绝，清除邀请并通知邀请方退出。
- `CMD19`：复用 28 字节背包移动格式，来源或目的容器为 4 时表示交易框。源 `value` 是模板 ID，源 `reserved` 是数量；金币的源槽和模板均为 0，金额按增量放入或取回。本人 `ACK19` 回显方向与实际交易槽，对方 `NOTI15` 更新 123 字节交易行。
- `CMD24`：`05` 锁定、`01` 确认，其他值取消；`NOTI17` 通知对方状态，双方锁定后发送空正文 `NOTI655`。
- 成交发送 `NOTI18`：`count:u16`，随后每行 `tradeSlot:u16, destinationSlot:u16`；再发送 `NOTI1681` 同步资产，不发送 `NOTI16`。取消或退出发送 `NOTI16` 并恢复对应槽位的显示。

物品实例、金额、槽位、锁定和携带上限由服务端验证；未经确认的字段和错误码不推断为通用成功。税费、次数惩罚和特殊展示未确认，不能据此推断支持。
