# 异界气息赋予

本页记录裂魂装备的第三期异界气息赋予，不是[异次元属性](异次元属性.md)的204/205净化与增幅。枚举为`CmdPacketType.ENCHANT_3RD_CHRONICLE_ITEM`，本版命令370；业务见[背包与装备](../模块/背包与装备.md#第三期异界气息赋予)。

## 请求与回执

ARAD生产者`039476D0`中的`03947871`创建370，随后依次调用写2/4/1/2/4/1字节接口，正文固定14B：

```text
materialSlot:i16, materialItemId:i32
targetList:u8, targetSlot:i16, targetItemId:i32, optionNumber:u8
```

源来自Main。目标容器字节不能遗漏或按旧端13B布局错位读取；当前业务只处理Main目标，已穿戴及其他容器保持拒绝。名称、说明文案不参与身份或技能选择；使用原声明的选项编号，不把它当技能模板ID。

CMD370在`0237C312..0237C31E`注册至消费者`0236EEF0`。消费者先调用`029CF9D0`弹出等待，无论成功或业务失败都需要完整终态回执，不能只记未实现或回空正文。失败为`0:u8 + error:u16`；非法资源和畸形正文使用17，身份不存在使用4，目标条件不符使用19，安全锁使用214，失败返还容量不足使用21。数据库异常仍沿原连接关闭及事务回滚合同，不伪装为业务拒绝或成功。

已提交尝试的回执如下；`succeeded=0`表示真实消费气息并破坏装备，不是前置校验失败：

```text
1:u8, materialSlot:i16, materialRemaining:u16, succeeded:u8
targetList:u8, targetSlot:i16, refundCount:u8
{ slot:i16, itemId:i32, count:i32 }[refundCount]
```

成功无返还时仍为完整10B。`0236EEF0`依次读取源槽、绝对剩余数量、结果、容器、目标槽和返还数量，不能复制旧端只带源数量及结果的短回执。源归零由原生消费者清源槽；失败消费者移除目标，并逐行处理返还。

## 属性与包序

普通123B核心原有`Chronicle0/Chronicle1`完整保存效果模板ID、职业、原始转职、装备类型及选项编号。写入的是该颜色的原始效果模板1254至1257，而非本次消耗的闪亮或活动气息编号；匹配客户端按原效果模板的导入表读取技能效果。

成功结果窗670按目标槽读取装备，故成功先以既有无获得播报库存投影安装实际提交的目标核心，再发ACK370。源已由ACK按绝对剩余量处理，不重复发送扣除。失败先回完整尝试结果，再以原有投影校准实际返还和钱包；不补造未经提交的新UID或属性。

旧端`df_game_r`的`Dispatcher_Enchant_3rdChronicleItem::read(081D35FE)`及`CItemUpgrade::ProcUpgrade(0854A1BA)`是业务参考，旧命令371不是本版包号。`ProcUpgrade_3rdChronicle(0854A006)`仅安装被声明的选择，`isDoEnchant(0854977A)`根据是否已有第一条使用不同阈值，`make3rdChroniclePacket(0854A9AA)`区分颜色效果与当前消耗品模板。原码、构建、自有TCP和真实客户端交互验收分别报告，不以协议自测代替结果窗及实际技能表现确认。
