普通建角与角色/技能/初始装备同事务写入 `accepted_story_level=1`、第 0 槽 `quest_id=3145, condition_state=1`；其余 29 槽为空。3145 的单清图 Boolean 初始未达成为 1，达成为 0，不可把 0 作为初始化值或推广成所有任务的状态枚举。

ACK4 携带进行中任务，NOTI356 携带已完成表，NOTI1382 携带已接受剧情等级；三者不能替代。字节布局分别见[角色与入城](../协议/角色与入城.md)和[主线任务协议](../协议/主线任务.md)。选择、城镇移动、返回选角与重登保留进行中槽，诊断副本死亡不推进条件。

任务表随[完整数据库基线](../开发/数据库.md)建立，包含已完成任务、进行中槽及 condition_state。新角色的剧情等级和初始任务由建角业务写入；数据库初始化不补发任务或修改已有进度。
