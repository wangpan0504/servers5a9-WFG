# 交易

交易双方在同频道城镇内邀请、放置物品和金币、锁定并确认。协议形态与包序见[交易协议](../协议/交易.md)。

`Game.Trade.TradeRegistry` 持有短生命周期的邀请与报价，不持久化；每个角色同时只参与一笔交易。报价保留选角代次、账号 generation 和完整物品实例，放置时不扣除资产；取回只修改报价。注册表锁不与账号租约、数据库事务或网络发送交叉持有。

双方确认后重新检查会话、角色快照、金币、物品资格和接收空间。`AccountOwners.Lease.ExecuteTogether` 固定账号锁序，持有双方租约，使用同一数据库连接和事务转移实例、更新双方背包与金币；提交后才安装两侧会话快照。任何写入失败整体回滚。提交结果未知时断开两侧连接，重新读取持久状态，不能报告成功或按旧快照恢复。

取消与离开会清除原交易实例并通知对方；成交使用 `NOTI18` 后的 `NOTI1681`，不发取消通知。除金币外，虚拟钱包槽暂不参与交易；交易税、交易次数限制与惩罚、账号级限制物品、宠物与称号的特殊展示不在当前范围；交易次数限制物品暂不接受。双客户端界面和未知协议字段仍需实机验证。
