# 交易

交易双方在同频道城镇内邀请、放置物品和金币、锁定并确认。协议形态与包序见[交易协议](../协议/交易.md)。

`Game.Trade.TradeRegistry` 持有短生命周期的邀请与报价，不持久化；每个角色同时只参与一笔交易。报价保留选角代次、账号 generation 和完整物品实例，放置时不扣除资产；取回只修改报价。注册表锁不与账号租约、数据库事务或网络发送交叉持有。

双方确认后重新检查会话、角色快照、金币、物品资格和接收空间。已到期物品在进入仓储前提前取消；未到期的普通期限可以进入提交。`AccountOwners.Lease.ExecuteTogether` 固定账号锁序，持有双方租约，使用同一数据库连接和事务转移实例、更新双方背包与金币；提交后才安装两侧会话快照。取得 writer 之后、转移物品或金币之前，用仓储时钟和系统时间的较晚值再核对冻结报价里双方全部转出物品的截止。已到期则整笔取消，双方资产、托管和成功回执都不变。任何写入失败整体回滚。提交结果未知时断开两侧连接，重新读取持久状态，不能报告成功或按旧快照恢复。

取消与离开会清除原交易实例并通知对方；成交使用 `NOTI18` 后的 `NOTI1681`，不发取消通知。除金币外，虚拟钱包槽暂不参与交易；交易税、交易次数限制与惩罚、账号级限制物品、宠物与称号的特殊展示不在当前范围；交易次数限制物品暂不接受。放入交易框复用邮箱 `TransferError`：模板为相对天数或绝对日期、且没有周期删除声明的未到期可交易物品可以放入；租赁、每日期限、每周删除、未知或越界的周期声明、过期和不可交易类型拒绝，CMD19 回错误 1。双客户端界面和未知协议字段仍需实机验证。
