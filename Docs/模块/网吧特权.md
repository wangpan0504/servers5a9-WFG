# 网吧特权

网吧身份沿现有实例开关：数据目录缺少 `pc-room.json` 时开启，`{"enabled":false}` 关闭免费身份。GM `pc-room on/off` 只修改当前进程。关闭免费身份不撤销账号尚有效的128权益，也不授予黑钻。

## 主面板与环境

原生菜单1169打开 `UI/Event/PcBang/chn_pcroom_main.xui`。会员128通过1760投影，Actor独立网吧场所位同时取当前资格；两者分别负责菜单和物品使用环境。免费资格不写账号会员期限。关闭或到期时，服务端立即拒绝新的专用物品消费；本版不能用1760零期限或66的窄类型字段清除128，因此在安全城镇边界执行完整重选。进行中的副本不因此中断。

物品目录保留 `[item category] must use at pcbang`。使用礼盒、子盒和药剂时，以真实使用源复核当前网吧环境；关闭身份或付费资格到期后拒绝消费，不能仅凭曾领取物品绕过。资格与角色、选角代次、场景及账号owner一并复核。

奖励、Buff和租赁候选读取本版 `etc/chn_qqpcroompremium.etc` 与 `etc/pcbangrentalservice.etc`。武器候选按当前职业及等级档选择，不信任客户端提供的物品编号；强化、锻造保留资源声明。目录只按实际格式和字段校验。

租赁档位等级与装备穿戴等级分别判断：本版女鬼剑的1级租赁档包含穿戴等级10的武器，低等级角色可按该档租到背包；实际穿戴仍沿装备等级、职业、技能与有效契约的原规则，不修改模板等级或额外授予穿戴豁免。

## 每日领取和免费租赁

| 功能 | 规则 |
|---|---|
| 登录礼盒 | 每账号每业务日一次，同账号角色共享；领取本版key1的实际物品和数量 |
| 网吧租赁装备礼盒 | 每角色每业务日一次；领取后24小时到期 |
| 网吧武器租赁 | 按职业等级候选批量规划；已有同模板且未过期的租赁实例时整笔拒绝，不部分发放 |
| 特权Buff | 从本版key1读取Buff；本人实体重建后恢复，关闭资格时移除，普通领奖不重复添加 |

业务日固定UTC+8每天06:00；该日界只控制领取次数。租赁总盒、子自选盒和最终装备继承同一个绝对截止时刻，开盒不重新计算24小时。租赁与普通物品按完整核心分别叠堆，不改变同模板普通资产的期限。

武器自选盒的 `[booster equipment grade] 6` 按资源中的最上级要求，使用现有固定最高品质创建策略，并保留强化、锻造声明。其它未确认品级声明继续拒绝，不能截断为无修饰装备。

登录奖账号日戳、租赁奖角色日戳与实际实例、物理UID和一次角色CAS在同一库存事务保存。满包、旧快照或SQL失败不占领取次数；成功后才安装在线快照。每日领取只允许已就绪城镇角色，初始化和只读面板不发奖。

本版领取回调会立即重绘窗口，发布顺序为实际库存、领取状态、最终ACK。493成功ACK的旧物扣除列表为空，新武器只走真实库存通知，不把新授予槽误当旧物删除。

## 经验与疲劳燃烧

通关经验沿[角色成长](角色成长.md)的现有网吧分项；黑钻、契约、药剂和其它来源保持独立。免虚弱沿原普通副本退图规则。

燃烧选择按角色保存，默认不强制勾选；当前只开放有效网吧资格，不自行开放活动115。初选先同步网吧会员资格，再发送490，避免客户端把尚未勾选的燃烧入口隐藏；城镇切换成功后同步真实状态。新正式普通或剧情Run冻结本版资源中的独立经验比例。杀怪燃烧按本怪基础经验计算；通关网吧20%与燃烧100%只按原始通关基础计算，不复乘冒险团、评分、契约、秘药等分项。冒险团奖励独立显示，不合并基础栏。正常剧情路线接入同一真实疲劳owner，免疲劳及特殊副本仍按原边界排除。击杀通知及结算页的杀怪、通关燃烧分项均取本次实际到账数值，重复死亡报告和结算重放不累计加成。

燃烧真实费用为普通费用的两倍，逐房扣2，入场一次性费用和代号希望地区费用同样翻倍；
末池不足双倍时扣到零，保留原入场基本费用准入。倍率按本次入场冻结，组队成员分别冻结，
重复加载和结果恢复不重扣。无限疲劳继续免扣数据库余额，与燃烧经验及[无尽大冒险](无尽大冒险.md)应耗产币兼容。

## 资源与验收边界

当前资源没有六阶段960/989的时间或奖池，也没有功能6。`pcroomtimepoint.etc`属于独立在线活动与632入口。协议字段见[网吧特权协议](../协议/网吧特权.md)。

`normal fiendwar index`是活动2481的结果提示目标索引。客户端在当前副本、Actor网吧位及活动资格同时成立时绘制“获得网吧狂欢节奖励”，该字段没有额外物品或数量合同；不据此复制或翻倍普通超时空免费牌，活动奖励仍须其独立的明确规则。

定向入口为 `--selftest-tcp pcroom-rules,pcroom,fatigue-experience`，核对规则/事务、真实网络包序及燃烧经验到账和显示分项。协议、资源和TCP验证不替代原生窗口点击、动画及实际战斗效果的客户端验收。
