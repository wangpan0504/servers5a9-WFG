# 春节宝藏掉落

启动时只在同一活动目录中精确春节范围有效启用后装配宝藏策略并读取活动装扮及宝藏模板；未配置、禁用或无效时不触发这些资源读取。目录在启动时确定，不新增运行中开启能力。已装配策略后关闭活动会沿同目录检查停止活动骰。

春节礼包活动有效启用时，使徒之赋采用本服明确规则：85级及以上角色实际穿戴使徒普通、克隆或至尊装扮的八个原部位，可混搭。只读取本人装备容器的槽0至7及真实物品实例；皮肤、武器、背包中装扮和借用外观不补足部位。物品必须属于原三套装，满足本人职业、等级及期限要求。

普通地下城按本人入场等级与资源中的 `recommended level` 闭区间判断；没有该声明时按最低等级至基准等级判断。残缺声明不回退。已有明确特殊副本标签、团本、独立玩法、塔、断头谷和黎明裂缝等不计入。该规则是服务端采用的活动规则，未声称恢复原活动所有隐藏地图判定。

每名合格角色对每个权威Boss死亡独立进行一次10%判定。队伍共享路线按潜在合格成员预留容量，个人推荐等级单独计算，不复制队长资格。真实普通奖励先生成，命中后追加一份神秘宝藏；每怪最多500个原预留对象，超出时拒绝入场，不能截断原奖励。

活动结果在首次死亡资产生成时冻结，包括未命中的空结果。晚事务失败后重试、重复死亡通知或之后更换装扮均不重抽。继续使用原死亡成长、地面物品、持久化与拾取事务：提交完成才发布，拾取归属保持本人，重复拾取不重复发奖。

原神秘宝藏模板未声明绝对日期、相对天数、每日或每周删除，创建后的期限为0，表示永久；绝对期限设置的两种取值均不会将它变为过期物品。本活动沿用已有物品创建与商城期限设置，带期限模板仍保留对应的绝对、相对、每日和每周规则；忽略绝对日期不会自动抹除其它期限。普通怪物掉落期限不变。活动禁用或配置无效时不投活动骰、不产生宝藏。后续开启宝藏仍由原随机盒消费者校验所需材料并同事务扣除、发放奖励。

回归入口：`SpringTreasureDropTests.RunCore`、`RunResources`、`RunPartyResources` 以及 `FormalDungeonSessionTests.RunSpringTreasureProducer`。个人冻结组队模型使用合成路线，正式死亡与持久化回归使用实际资源；它们不替代客户端实机显示证据。
