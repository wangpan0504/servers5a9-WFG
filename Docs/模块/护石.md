# 护石与符文

护石和符文的类型化资源解释由 [ItemCatalog](../../Server/DfoServer/GameWorld/Items/ItemCatalog.cs) 提供，复用同一装备、堆叠物品名册与 PVF 归档。首次查询解析，后续查询共享不可变定义。未知编号或非对应类别返回无定义，畸形声明明确失败，不补造职业、首转、技能或阵营。

## 资源与资格

- 护石按 `[equipment type] [talisman]` 识别，附加整数是资源子类型，不是客户端装备槽。`[useable growtype]` 与 `[rune skillIndex]` 分别保存首转限制和技能。缺少这两个字段的零品级、全职业占位物保留为不可装备定义，不视为任意职业的有效护石。
- 符文按 `[stackable type] [rune]` 识别，保留 `[usable first growtype]`、`[rune skillIndex]` 与 `[rune option]` 的阵营、品级。`terracotta`、`circlemage`、`guardians`、`antiquitylibrary`、`secondpact` 分别映射孔色 1 至 5；模板堆叠上限为 999。只有当前 `stackable.lst` 注册的资源进入目录，归档中的孤立文件不充当有效候选。
- 使用资格同时检查模板等级、职业和首转。GrowType 高位的觉醒状态不改变首转限制；重复、空白、越界或嵌套的关键声明拒绝，不按默认值放行。
- `etc/runesystem.etc` 的合成和随机选择重复块保留原值、原序。重锻材料与各品级数量由独立字段装配；未知品级不补造费用，商店 `[need material]` 不作为重锻附加成本。

## 库存与历史兼容

内部分类为 `Talisman=11`、`Rune=14`，与资源子类型分开。客户端容器 46 共 216 格：护石背包 0–69、符文背包 70–209、已装符文 210–215。护石穿戴于装备槽 34、35，各自对应连续三个已装符文槽。自动发放按类别进入对应分页；合堆只查背包格，不能向已装符文槽增加数量。

登录兼容仅接受资源确认的历史 `Equipment→Talisman`、`Consumable→Rune`。原 Main 实例迁往对应分页，个人及账号仓库保留原容器和首份位置；超上限符文守恒拆分，第一份保留 UID，额外份在事务中分配新 UID。完整核心、锁和未知位保留。容量不足时整批延后，保留旧分类和位置并允许登录，不截断或删除资产。邮件领取及拍卖归还同样保留原快照供提交复验，输出时才归一分类。

数据库迁移只开放容器 46，不猜测物品编号或批量改写核心；资源兼容通过既有库存提交器落库。库存、邮件、仓库与拍卖的公共行为见[背包与装备](背包与装备.md)。

## 装卸与重锻

装入从符文背包取一枚真实实例，保存到 210–215。单枚移动保留 UID，堆叠拆出的一枚分配新 UID；替换时旧符文先规划返还，容量不足整笔拒绝。同一护石的三个孔不能重复同阵营、同技能符文；两枚护石分别检查。错色允许装入，三孔齐全且逐孔匹配才由客户端激活附加效果。普通移动请求不能代替专用符文装卸；已装符文槽也不接受普通删除、出售或锁定，资产只能经卸除整枚返还背包。

护石和符文装入均检查等级、职业、首转、期限和安全锁；卸下允许返还没有父护石的孤立符文，父护石存在且锁定时拒绝。卸下、替换和重锻复用库存计划与单次事务，失败不产生部分资产变更。锁外规划后，回锁复验角色引用、选角 epoch、阶段与原始库存，再提交；成功回包只使用实际提交回执。

三孔颜色位于 `Extension114.Value` 的低 24 位；高字节、扩展 Flag、旧 `ItemCore.Rune:u16` 及 `Extension119` 保留。新实例与重锻共用服务端生成策略：五色等权、不重复抽三色。该策略不是已证明的原服概率；旧实例的重复颜色仍合法。重锻从 Main 指定材料格扣除当前资源表声明数量，同时替换护石背包目标的孔色，不额外重建实例或清除其他核心属性。

## 同步与未实现边界

登录发送容器 46 全量，普通变化使用同容器差量；已装符文变化另刷新本人 Player 的六个符文编号。装载槽中的真实实例只持有一份，装备尾部编号向量仅是效果投影，不再创造道具。

重锻结果窗立即按回执槽位读取孔色，因此成功先投影已提交目标，再发送回执，最后发送权威差量覆盖客户端预留返还。业务拒绝发送失败回执并恢复容器显示。

合成请求已有严格解析，合成业务及其成功处理尚未接入。资源中的合成件数与金币费用已有消费证据，其他两列及随机表 scalar 语义仍待确认，不据猜测扣料或返回成功。邮件附件 Type 使用来源容器号，服务端接收 46 的背包格并在回执后恢复权威数量，装载槽不能直接寄送；客户端护石界面的附件选择路径尚未实机确认。装载、卸除、重锻与登录迁移已由 TCP 回归覆盖，客户端验收仍待实机进行。
