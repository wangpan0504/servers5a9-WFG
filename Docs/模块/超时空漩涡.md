# 超时空漩涡

## 频道和玩法边界

频道39、type45、分组`[fiendwar]`进入团队城镇57。57/0为门厅，57/1为NPC624所在招募区域，57/2为NPC625所在团队候战区。候战门要求真实未开战攻坚队；进入候战区不提前扣票。无公会可创建、加入和开战；抗魔仅作提示，95级、前置任务和真实门票仍须满足。

普通超时空之战使用城镇115、世界地图201、DGN400000016，沿普通type22入口进入，保留90级、疲劳和独立门票。主线城镇55也属于另一条路线。普通城镇及地下城不能借type45进入，团队和引导地下城也不能借普通频道进入。选角、出房间、城镇门和正式选图均校验对应边界；客户端配套清理进出type45的跨频道城镇快照。

## 团队战场

团队最多8人，区域遭遇1至4人，允许一人开战。统一使用完整三路战场、同一状态机及结算；成员可分路并行，也可先后完成目标，不依据人数切换剧本。费用、候战位置和生命周期沿原全团外层事务提交，重复开战不再扣费。

总限时保留3600秒。`FiendwarPacing`统一将出兵、推进、前哨/兵营恢复、局部战斗限时和商人停留乘2；总时限及罗什原输出窗口不乘倍率。基地入侵和总超时仍失败，撤退、战败及局部超时不增加罚站。三兵营全部完成前保留恢复压力，全部完成后锁存解锁成果。

区域移动、遭遇成员、怪物/迷宫随机、计时锚点归原Battle。局部参战名单和缩放在遭遇创建时冻结，不因掉线重抽或降血。当前客户端私有怪物属性包接入HP倍率；攻击倍率尚无已验证客户端消费者，不能将领域公式或攻速字段当作攻击伤害已生效。

双世界各自保留真实元素机制和原长度本体输出窗口，完成结果保存在同轮聚合内。成员可正常回战场换边，双方必需目标及真实终图死亡齐备后才进入一次最终结算。断线原实例保留300秒，恢复不刷新随机、HP和成果。

## 官方引导

官方引导使用独立`single`资源、57/33至57/43、DGN5350至5358、入场票10309054及1800秒总时限；不套团队放缓、组队缩放及双世界接力。路线依据同一类型2的当周通关次数选择原版两条路线，实际迷宫仍取引导目录。引导允许无限复活币，团队复活限制独立保留。

引导和团队共用类型2的入场、通关和领奖账本及日周资格，周二06:00（UTC+8）换周。开战同事务绑定账号当周最多两名引导角色；失败仍保留真实入场历史和绑定，不退回通关额度或额外制造免费资格。

## 攻坚队面板

创建、招募列表、搜索及详情中的模式标记均来自实际团队/引导选择；允许一人开战不代表引导模式。申请和邀请沿同一名册准入，改名、编队、委任与踢人复验真实团长身份。踢人只关闭被踢者的面板，不向团长发送自身退团回包；开战前可重新申请。

四类团本卡的日周已用次数读取原`character_raid_runs`中已提交的整团通关；局部清图、首阶段、未通关入场和领奖次数均不作为整团通关。初始化、真实终局和业务日切换刷新1446，重复同值不重发。漩涡选角悬停与卡片沿同一周二周期；卢克沿实际装配的开战周期，其余团本保留各自现行周期。未核证的1446子表及账号引导绑定通知不填造正文，绑定UI仍须匹配客户端取证。

## 失败退票和奖励

团队及引导真实系统失败时，仅当前仍在团的原付费成员获得本次所扣票种和数量；主动离团、断线放弃不因之后失败补退。扣票计划冻结实际消耗的完整物品属性及期限，不重新生成新期限。失败能力只由已激活原Battle的失败快照产生，客户端请求不能直接指定退票。

存储核对原实例、账号、角色、来源、入场时点及尚未通关的生命周期。关闭原入场行和系统邮件投递共用一个事务；稳定`fiendwar-refund:<instance>:<character>`键与原邮件完整内容充当退款收据。SQL回滚不留半封邮件，重复回放不二次退票，已被新入场放弃的旧行不补发。忙锁沿原有有界退避重试，已密封失败不会因终态或最后成员离开而丢失重试。

最终奖励先冻结每人完整结果，再沿原资格、领奖事务和满包邮件路径提交。材料实际数量来自本地末期礼盒内容；外层权重是本地资源声明，不宣称为国服公开概率。网吧和特权额外奖励须有真实资格，不能普发。

## 客户端配套和验收边界

1522开始通知、1524敌军警告、1526至1530战况及机制通知沿匹配原生消费者编码。1528推进、设施和局部倒计时均发送Unix截止时点及持续秒数；发送缓存只记实际写帧成果，删除使用完整零截止/零持续行，重复快照不重设原倒计时。

区域非零15先为遭遇成员建立选图场景；城镇直接16也先发布同一选择回执及27，再安装加载并发送28/29。已有选图场景不重复发送27，重放加载不重新建图。

随机商人沿原生NPC626生成和区域显示链；商店305购买必须处于当前有效商人区域、原团、城镇状态且未过期，规划及提交前均复验。雷达、炮塔已有原生战斗效果链，客户端分别读取`radar skill attack bonus buff rate`和`battery defence debuff rate`；不重复加服务端补偿。城镇移速时间、倍率是另外两个字段。

客户端补丁还需移除两处已证明的type45公会门禁。团队冰牢自动脱困差量由[可重现资源工具](../../Tools/FiendwarResourcePatch/README.md)生成，只追加十秒调用既有解除行为，保留原队友救援及每200毫秒扣1%HP；官方引导资源不改。

服务端TCP、离线原码和实际DLL夹具不替代游戏实机验收。自然创建、选图、战斗招式、双世界交接、冰牢脱困、奖励展示及引导绑定UI仍须QA逐项验证。未验证机制、攻击伤害缩放和未闭合的逐怪掉落不能计作完整还原。
