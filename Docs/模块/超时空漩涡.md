# 超时空漩涡

## 频道和玩法边界

频道39、type45、分组`[fiendwar]`进入团队城镇57。57/0为门厅，57/1为NPC624所在招募区域，57/2为NPC625所在团队候战区。候战门要求真实未开战攻坚队；进入候战区不提前扣票。无公会可创建、加入和开战；抗魔仅作提示，95级、前置任务和真实门票仍须满足。

普通超时空之战使用城镇115、世界地图201、DGN400000016，沿普通type22入口进入，保留90级、疲劳和独立门票。主线城镇55也属于另一条路线。普通城镇及地下城不能借type45进入，团队和引导地下城也不能借普通频道进入。选角、出房间、城镇门和正式选图均校验对应边界；客户端配套清理进出type45的跨频道城镇快照。

## 团队战场

团队战场当前有效遭遇中的权威敌方死亡，为有资格的实际参与角色推进战令每日击杀任务；原资源标记为Boss时同时推进领主任务。各角色沿原死亡回执独立提交，等待数据库写入前冻结的有效资格不因等待跨越战场或遭遇时限而失效。

团队最多8人，区域遭遇1至4人，允许一人开战。统一使用完整三路战场、同一状态机及结算；成员可分路并行，也可先后完成目标，不依据人数切换剧本。费用、候战位置和生命周期沿原全团外层事务提交，重复开战不再扣费。

总限时保留3600秒。`FiendwarPacing`统一将出兵、推进、前哨/兵营恢复、局部战斗限时和商人停留乘2；总时限及罗什原输出窗口不乘倍率。基地入侵和总超时仍失败，撤退、战败及局部超时不增加罚站。三兵营全部完成前保留恢复压力，全部完成后锁存解锁成果。

三兵营的量子时空传送站共用正式区域移动和遭遇准入。暗、白区域各只回连一座兵营；原生确认从其它兵营发出默认坐标0,0时，在来源路线已通过后按目标图真实可走区域解析落点。该回退仅限活动漩涡的兵营至暗白原生路径，三兵营解锁、区域容量、当前成员、时限和整队位置事务继续生效。

区域移动、遭遇成员、怪物/迷宫随机、计时锚点归原Battle。局部参战名单和缩放在遭遇创建时冻结，不因掉线重抽或降血。客户端私有怪物属性包MAI3（80字节）在房间通知前携带HP及攻击倍率；配套补丁在原生怪物完整属性初始化末端分别改写物理、魔法攻击的加密基值。四人及以上原倍率不额外覆盖，官方引导不套团队缩放。新协议须先安装配套客户端资产，再发布发送端；不能用领域公式、攻速或TCP终杀代替自然伤害的实机验收。

双世界各自保留真实元素机制和原长度本体输出窗口，完成结果保存在同轮聚合内。成员可正常回战场换边，双方必需目标及真实终图死亡齐备后才进入一次最终结算。断线原实例保留300秒，恢复不刷新随机、HP和成果。

本体权威死亡允许先于1554保存报告到达。当前输出窗口内（含原五秒报告宽限）的真实终杀保存本侧零血量并安全返回战场；另一侧机制尚未完成时不生成整团通关或奖励贡献。最后一侧真实终杀可以直接完成双方汇合和最终结算，无需对已经死亡的本体再次上报死亡。机制未完成时提前击杀只退出原遭遇，保留未完成机制供重新进入，不借单房死亡跳过双方条件。晚到旧Run报告不能改变新遭遇。

两模式合计每角色每周最多两次通关、每业务日最多一次通关，账号每业务日最多十次入场。切模式不能取得额外资格；通关事务即冻结奖励并消耗本次通关额度，不等待实际翻牌。跨日、换周和另一模式入场后仍按原实例、来源、周、event及anchor读取已冻结产物，不按当前模式重抽。

## 失败退票和奖励

总期限到期后沿原退场事务返回战场或招募区；原攻坚队身份有效时先写出1523状态5失败提醒，再通过665强制离队关闭旧团。仅清理捕获的原失败实例，随后同一角色可以重新创建攻坚队并正常开战，旧退场回调不能拆除新团。

失败展示仅在实际退出副本或选图、回到城镇后发送；失败或胜利终态不再投递战场单位、计时器和电影事件快照，避免原生战场清理后继续操作旧对象。失败后全新连接选角沿频道规则回共享房间，再通过1426进入57/1招募区；旧57/2及后续战场坐标不能作为可恢复城镇快照。原连接失败离团也回57/1招募区。

团队及引导真实系统失败时，仅当前仍在团的原付费成员获得本次所扣票种和数量；主动离团、断线放弃不因之后失败补退。扣票计划冻结实际消耗的完整物品属性及期限，不重新生成新期限。失败能力只由已激活原Battle的失败快照产生，客户端请求不能直接指定退票。

存储核对原实例、账号、角色、来源、入场时点及尚未通关的生命周期。关闭原入场行和系统邮件投递共用一个事务；稳定`fiendwar-refund:<instance>:<character>`键与原邮件完整内容充当退款收据。SQL回滚不留半封邮件，重复回放不二次退票，已被新入场放弃的旧行不补发。忙锁沿原有有界退避重试，已密封失败不会因终态或最后成员离开而丢失重试。

## 公会贡献

公会入场门禁取消后仍保留真实通关贡献。开战扣票事务冻结原公会和入会代次，最终合格通关与贡献在同一事务提交；局部清图、罗什机制报告、翻牌及重放均不单独发分。基础250，同会2/3/4人按1.5/3/4倍；只计本人最后一次真实清图小队内、具备本次最终资格且原会籍仍有效的成员。动态换队采用最后真实清图队伍是本服兼容规则，不宣称已证原服取样时点。八人整团不截成四人，无真实清图、中途入会或退会重入不追领；迁移前旧run不补造会籍。独立引导沿相同账本按实际一人结算，不改变原版引导路线或奖励。

## 客户端配套和验收边界

1522开始通知、1524敌军警告、1526至1530战况及机制通知沿匹配原生消费者编码。1528推进、设施和局部倒计时均发送Unix截止时点及持续秒数；发送缓存只记实际写帧成果，删除使用完整零截止/零持续行，重复快照不重设原倒计时。

1524是六秒遭遇预警事件，不能用零值布尔快照清除；1530的121至125是执行电影事件，零值和同值再次SET也各自保留真实事件代。每连接仅在FIFO实际写帧后确认展示水位，普通进出怪物房和重复战况不重播。重返期间先恢复START，再播种断线前历史事件水位并补当前战况；PREPARE/START以原actor、会话及Battle实例守卫，不因迁城期间的战况revision变化丢弃START。字节及匹配消费者见[预警、电影与最终牌面](../协议/副本.md#漩涡预警电影与最终牌面)。

攻坚总时钟使用597槽0的相对秒数，团队3600秒、官方引导1800秒；首开战、重返及战况重放均从原战场截止在发送泵实际构包时计算剩余时间，旧实例、旧战况及已失效会话不发布。同实例同秒只写出一次，跨秒排队后在同秒写出的快照同样去重，避免反复重置客户端显示。原生`00DE9128`查询槽0，频道类型45的`01DD1752/01DD187C`以同一秒时钟保存和读取；1522注册的`046D14A0`仅返回，不承担倒计时。总期限到期或已终结时不续时，不附加未证的界面清理字段。

团长在战况板请求上、中、下路支援走C2S1570及NOTI1554，与1530机制符号分开。只有当前完整团队实例的真实团长可发出请求，全团共用三秒间隔，收件人冻结为当时的原会话代次；退团、换角色、超时、炸团或通知过期后不再播放。通知只在实际写帧后记已展示，后续移动、进退图及战况快照不重复播放，不修改兵线、Boss、奖励或角色资产。官方引导不启用三路支援。

专用持续属性药沿原消耗品保留位处理退场：单人和临时小队返回战场前在库存事务中清除未声明保留的效果，并清除对应冷却约束；保留位明确开启的普通状态仍按各自资源处理，不强清全部药效。兽人药沿独立城镇变身链处理，不能把它当作图内持续属性药。

罗什属性机制保留六晶体任意攻击切色及同色后的对应抗性降低。需要改变武器属性时沿既有晶之契约：已开通97权益的参战者可在图内发送535选择黑、白、红、蓝晶块，901及本人Player刷新对应原生虚拟装备，分别获得暗、光、火、冰属性。选择本身不扣材料，实际附魔仍按原装备每30秒消耗对应晶块1个、持续30秒；取消、到期及余额不足沿契约原规则，不因团本赠送契约或免费材料。这条装备属性链与DGN禁用普通消耗品分开，单人及临时小队成员共用相同规则；自然属性伤害仍须客户端验收。
