# 魔界冒险助手

客户端独立插件95Helper提供两页原生设置及独立功能开关。本模块只处理同地区深渊轮换，不接管连发、加血或普通拾取；掉落归属和拾取事务仍由现有地面物流程负责。

普通聊天CMD17中的保留文本为`#95-helper/1 <32位小写十六进制nonce> <当前角色ID> hell <0或1>`。Parser严格校验通道3、零附加值、完整长度和规范十进制角色ID，保留命名空间的畸形或跨频道命令也不广播。当前合法角色的关闭请求始终允许；开启限定单人城镇、选图或地下城。偏好绑定当前选择epoch，不能沿旧角色或旧会话生效。

设置回执使用NOTI1709，标题`95_HELPER/1`，正文`1|nonce|角色ID|epoch|ok或rejected|0或1`。提交偏好后才回应，发送前复核当前角色和epoch。客户端只对匹配当前请求的回执确认设置，不自动重发；此回执不是普通玩家公告。

首次深渊按正常入口和路线进入柱子房。清除真实阻挡怪、全部波次和待提交操作后，普通MOVE_MAP的真实邻门请求可准备同地区主选图列表中的另一张柱子图。候选只取当前角色满足选图资格的普通入口，排除任务进行中专用入口和没有合法柱子资源的图；末图回到首图，当前图不在列表或没有其他候选时拒绝。练习、任务、组队及特殊深渊不参与。新实例冻结首次地下城等级、怪物调级规则和难度，生成新的演员key及加载身份。

准备在owner锁外完成，安装前复核原实例、角色引用、epoch、门、偏好对象及未决状态。安装沿正常入场事务提交票、疲劳和尝试号，不额外计算费用；不足时保持旧实例及资产。发送顺序为MOVE_MAP成功、ENTER_SELECT_DUNGEON、DUNGEON_INFO、原AI信息、START_MAP和深渊信息、入场资产差量；CMD37完成新图加载后沿原链扣房间疲劳。重复加载不重复扣费。明确关闭后回到普通过门逻辑。

定向入口`--selftest-tcp helper-hell-rotation`覆盖真实聊天设置、首轮路线、清怪门禁、连续两次完整加载、票及疲劳、缺票拒绝和关闭后普通过门。资源测试HelperHellRotationTests覆盖冻结依据、身份、费用不足与组队后关闭。默认输入为纯净PVF；隔离测试不代表客户端画面已验收。
