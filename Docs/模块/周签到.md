# 周签到

活动2208「周周惊喜乐开怀」使用匹配S5A9客户端的每周签到窗口。未配置时间表或覆盖状态时默认开启；GM通过`event on 2208`、`event off 2208`或活动时间表控制，`event auto 2208`恢复时间表、无时间表时恢复默认开启，已有显式关闭和时间表继续生效。开启后加入完整108活动目录的普通行与active行，保留其它活动。

## 资源与规则

目录从`event/chn_event/chn_totalattendance.evt`读取实际XUI路径、周期、普通和补签费用、补签上限、每次签到奖励及累计奖励；不校验整包PVF摘要。

当前匹配资源为9周：普通签到消耗4次推荐地下城通关，补签消耗20次，全季最多补签2次。九档顺序奖励为490014139–490014147各1件，累计2／5／8次奖励分别为490014148／490014149／490014150各1件。每日签到、按自然周直接索引奖励和第二组累计奖励等不同模式明确拒绝，不解释为当前玩法。

当周未签优先签当周；当周已签且存在历史缺周时补最早缺周。发奖按领取前总签到次数取下一档，不按被补周号取奖励。累计请求一次领取所有已达到但未领取的累计档，初始化及轮询不自动发奖。

## 进度与事务

首次已开启的有效观察或推荐通关冻结全服赛季：起点是中国时间UTC+8当前周四06:00，终点是周期周数之后。真实激活前及赛季终点后不能领取。重启、开关切换和过期不会自动换季；已有赛季与目录周期不一致时保留进度并报错。

账号共享各周通关余额、已签周位图、累计补签次数和累计奖励位图。同账号换角、重连及重开仓储恢复原进度。损坏账本报错，不能重建默认进度；时钟倒退拒绝领取，也不增加通关。每周余额上限为普通费用加全部允许补签费用。

推荐资格复用本版已接受的[推荐地下城规则](副本.md)：正式结算的新回执分支才记数，周计数与原经验、角色revision和结算回执共用同一事务；重复结算不重计，活动关闭或过期不记数。客户端签到请求的opaque字段不提供通关次数。

每档奖励通过一封永久系统邮件投递给本次领取角色。附件复用统一奖励规划、堆叠和期限政策，真实物理UID由原邮件事务分配。全部邮件、附件和账号进度共用一个事务，晚失败全部回滚；领取不改角色revision、背包或钱包。重复请求及无变化观察不重写账本、不重发邮件。关闭保留历史邮件及领取事实。

数据库迁移196在主线v195之后新增`weekly_attendance_season`和`account_weekly_attendance`，不重建已有角色或资产。账号账本不随删角、邮件删除或角色复制重置。

## 发送与验证

入城就绪后初始化，原活动投影任务每30秒观察，GM开关变化唤醒，结算请求后立即观察。未变化正文按选角epoch去重，换角重新绑定。发送使用原账号lease及选角epoch；成功应答在持久提交之后。协议及匹配客户端证据见[周签到协议](../协议/周签到.md)。

无资源规则、Parser、完整459B正文、实际邮件与晚失败回滚、重开仓储和195→196迁移测试接入`--selftest-core`。`--selftest-tcp weekly-attendance`覆盖真实PVF规则、原通关事务回滚和回执重放，以及TCP默认开启、开关、签到、补签、累计领取、换角共享、附件和包序。测试的签到余额准备与真实通关事务验证分别进行。客户端界面和人工操作验收独立于这些自动化检查。
