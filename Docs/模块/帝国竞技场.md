# 帝国竞技场

帝国竞技场使用特殊频道 `48/type39`、城镇 `48/0`，与再战魔界 `type53` 分开。当前接入普通 `320` 与困难 `336`，双角色、正式副本、奖励和每周荣誉由本模块管理。客户端可见表现仍需实机验收，自动验证不能替代画面、切角手感和技能效果验收。

选角及跨类型换频道直接进入48/0准备场景，不经过共享赛丽亚房间。同类重连保留正确的场景快照；旧存档仍在共享房间时重新按频道落点准入。准备场景不覆盖角色进入前的普通返回地区，离开频道仍沿普通房间返回规则。

## 编队与入场

原生设置窗口299先以空正文CMD1470请求名册就绪；共享CharacterHandler回复NOTI1408的其他大区数量0，复用已发布本区真实名册，不重发普通Actor或名册。该查询不写编队与资产，合同见[角色协议](../协议/角色与入城.md#编队请求已确认边界)。

`ImperialArenaConfiguration` 保存同账号两名不同的稳定角色 ID 与独立 revision，客户端索引只映射实际发布的选角名册。两名角色均须至少90级，不能是决斗专用角色。备用角色的真实技能、穿戴及期限须先完成正常选角维护；资料不就绪时提示分别登录，不伪造角色。以编队第一名登录后，沿真实主角 Actor/Player 发布 `1393→1394`，备用不替换 Session.Selected、账号 owner 或邮件收件人。

帝国频道首次入城时若编队为空，就按当前角色为队首、名册里第一名其他至少90级非决斗角色为备用，经原配置事务保存一次；备用角色未完成技能初始化或资格不符时不写入，不猜第二人。空编队没有 `1393→1394`，客户端拿不到 `runtimeActor`，左上角只剩 "Tag" 占位圆圈，队伍设置与入场按钮都无响应，所以自动配队是首次进入玩法的前置条件。

每日06点为日界。首次购买挑战券扣15万金币并固定当天普通或困难模式，再次进入不重复扣费，日界前不能换模式。购券要求当前有效已发布双角色；持久层在同一事务重新核对双方归属、等级及非私有身份、角色 revision、金币和日券。扣金币与创建日券整体成功或回滚。

已发布的双角色只随主角身份、账号钱包版本和备用角色投影到期判失效；主角走位、技能、经验与体力变化不改动已装好的双 Actor，不再要求重登。购券与CMD15准入前发现已装双角色失效时（例如进场前修理扣了金币），当场重发一次 `1393→1394` 再继续；重建失败才按原准入规则拒绝，并在 `imperial_arena_pair_refresh_failed` / `imperial_arena_entry_rejected` 记录原因。

帝国频道、实际城镇位置和合法编队才能取得专用6B CMD15许可；随后25B CMD16消费同一选择代次、已付模式和本日路线，正式 attempt 与准入记录同事务提交。普通单角色入口、练习、任务、地狱、组队和再战准入不能借用帝国图号。

## 对手、战斗与退出

`imperial_arena_daily_routes` 保存全服同日统一的普通五名、困难七名对手及弱点；候选来自本版资源，以业务日和候选身份确定性排列、首写后复用，重登或重启不重抽。普通首房准备，随后四普通对手和竞技之王；困难首房准备，随后七回合。真正房间 X 坐标与回合一致，地图和指定领奖怪物逐项匹配，1400公布顺序就是实际路线。

元素弱点编号为火0、水1、暗2、光3、无4；普通竞技之王无元素弱点。共同弱点0魔法、1物理。客户端从1400保存弱点并用于战斗属性计算，困难倍率按实际房间 X-1 读取资源七回合表，服务端不重复缩放 USERINFO。普通4000、困难10000的“帝国的荣耀”由原生模式判定安装，六个专用免费快槽由原生资源路径生成，不创建或扣减普通背包药品。

1403第三字节公布当天已清前缀，普通按固定路线的已领奖对手数、困难按本日累计最高回合，重登后恢复头像灰显。普通第四名对手清理后的继续按钮由原生恢复双角色资源并清技能冷却，困难不走这一恢复流程；服务端死亡槽仍不复活。

Session/Run持有两槽生命状态与2秒切角冷却；单角死亡切到存活角色，死亡槽不能切回，帝国不安排再战的12秒复活。双死才确认终局败北。切角不更换登录队首持久身份。战斗期间普通库存消耗品、技能变更及装备变更均拒绝，耐久报告不能更改已穿装备；返城后恢复普通城镇操作。

完整路线最后一回合奖励事务提交后，在1402及必要邮箱通知之后发送空正文31，设置客户端专用场景的通关状态，再发送1401打开专用结果窗并完成头像进度。结果使用本次真实耗时，当天已领取全部奖励后重打仍展示结果；中途及重复击杀不发，不转入普通翻牌结算。旧版全服排名未接入，结果不伪造旧榜数据。

CMD42使用正式实例返城，保留已发布双角色，由24的原生离图恢复已有队首、技能与UI；任务刷新及必要困难恢复邮件通知之后只公布日券、对手和周挑战，不额外覆盖普通Actor/Player/技能或重建1393/1394。新会话入城仍按正常合同安装双角色。每个06点沿连接既有日界任务刷新城镇资料；进行中的实例保留原日奖励归属。困难周四05:30至06:00拒绝新准入和购困难券，跨周或关闭窗口完成的成绩不回写旧周榜。

本版客户端另有每日05:31至05:59的界面入口门禁，与官网周四困难门禁区分。资源的返城字段`5 30 10`尚无实际消费者证据，不能解释为05:30:10或自行新增强退计时器；等待区和技能自然表现列入实机验收。

## 材料奖励与恢复

最终结果菜单沿客户端原生CMD72：`state=2,option=2`只确认返城选项，`state=1,option=2`才执行返城。仅当前帝国实例末轮奖励已经提交并进入结算后接受，复用原返城和帝国城镇资料刷新；不创建普通经验或翻牌结算，不再次发放奖励。中途请求及退出实例后的迟到请求不授予返城成功。

只有本实例正式准入后、当前真实房间中指定对手的已准备击杀能提交奖励；其它怪物和普通结算入口不能直接授予奖励。账号、原业务日及怪物构成唯一领取资格；普通按本版权重抽样，困难按累计表只取本日新增差额。随机结果、完整附件和事件身份先冻结，重试不重抽。

配置探险记任务时，只有上述当前轮真实对手死亡才在同一回合事务写入独立击杀来源、当前任务进度及季版本；准备房、友方、APC和其它TAG玩法不借用该来源。领主任务仍服从原怪物IsBoss标记，进度不自动兑换任务经验。来源或进度写入失败时，回合、奖励、邮件与任务一并回滚，原pending和随机奖励保留重试；已提交事件重复读取原奖励，不回填历史任务。原死亡及1402、必要99和末轮31/1401发布完后，沿当前实例与角色守卫刷新1801。

普通每名对手投递一封永久材料邮件。困难逐回合只保存冻结附件和账号日进度，在完整通关、主动放弃、双死或断线时将本次新增差额合并为一封邮件。邮件、附件、资格引用和实例关闭同事务提交，异常不得只关闭实例或先发成功通知。启动时核验材料为永久账号材料、堆叠上限可容纳完整困难累计，避免合并越界。

旧 owner 无权写入时，由新 owner 在帝国城镇初始化恢复未结清实例，不在进行中的副本提前结算。删主角色在删除事务中先结清其固定收件人的未关闭实例，再沿已有删角语义清邮箱；账号日资格和周成绩保留，不转发其他角色、不重置资格。

## 每周挑战

本版界面为“困难模式每周挑战”，周四06点重置。只接入资源真实存在的周荣誉道具 `10304868`；道具和使用后伤害字体均14日，沿已有皮肤仓库能力使用。1618领取与唯一周事实、完整荣誉附件和邮件同事务提交，同账号每周仅一份；重复请求返回原邮件事实。

本服目标规则为：取上一完整周每账号最快有效七回合成绩，按耗时、账号排序，使用资源名次20000的时间作为本周目标，样本不足则用配置240000毫秒。至少达到配置30000毫秒、耗时可用u32表示、在原准入周且关闭窗口前完成的完整困难挑战才计榜。1632返回本周个人最快成绩、真实职业快照、目标和领取位。该目标算法是本服明确规则，不冒称原服未公开算法。

旧官网前200排行奖励与本版周挑战不同；当前PVF没有旧排行奖励表。1463查询真实上周个人名次，1464明确拒绝不存在的旧奖励。客户端旧全榜页硬编码外部网站，本模块不宣称提供本地网页全榜。

## 持久化和验证入口

帝国使用每日路线、编队、日券、正式实例、日对手奖励、周荣誉领取六张独立表。迁移暂排126；整合时按实际队尾重排，连同完整SQL和升级夹具同步，不在运行库单独执行本任务迁移。

自动验证入口为 `ImperialArenaTests`、`ImperialArenaPersistenceTests` 与 `--selftest-tcp imperial-arena`，覆盖字节合同、两模式完整路线、日券/奖励幂等、普通操作拒绝、真实断线、邮件及周资格故障回滚、删角恢复、周目标样本及同分排序。具体原生依据和包序见[副本协议](../协议/副本.md#帝国竞技场专用协议)。
