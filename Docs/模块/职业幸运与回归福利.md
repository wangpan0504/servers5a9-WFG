# 职业幸运与回归福利

原生四叶草读取 `etc/chn_activatecharacter.etc`。GM指定基础职业时，按当前CHR实际成长分支下发该职业全部转职及觉醒；未覆盖时读取资源日程，零日期日程不授予资格。NOTI1057正文为`count:u32 + {job:u32, growType:u32}×count`，在本人Actor与技能表前发送，包括空名单以清掉上次连接残留。客户端原生系统据此安装3017四叶草图标，并消费同一资源的Lv1–85技能+1、排除EX技能配置；不修改已学习等级或向数据库永久增加技能。

职业组队活动独立读取 `event/partybuffeventasjob.evt`，按基础职业、转职及队伍内匹配人数选择原生Buff。默认目标为女格斗全部转职，1/2/3/4名匹配成员分别对应队友1087/1088/1089/1089。本人使用独立的 `[party job buff info]`，当前为空。四叶草GM不改写这套活动的目标、Buff或人数档位。

回归资格按账号保存，福利期限来自 `event/chn_event/200114_newreturnsystem/chn_returnsystem.evt` 的 `[benefit period]`，当前28天。`chn_event_returnsystem.evt` 的返回者/现役队友Buff当前均为1273；至少两人处于同一正式副本且有有效回归账号时，分别给双方对应Buff，同索引不重复。资格到期、返城或队友离开后重新计算并清理。账号资格由GM设置，不复用旧角色JSON的 `LegacyReturningPlayer`，也不推断自然离线天数。仍有效时重复设置GM不更换周期或延长资格，防止重置领取账本。

`AdventurerBenefitStore` 在 `Data/adventurer-benefits.json` 持久保存目标职业覆盖值及账号绝对期限，先Flush并原子替换文件，再发布不可变配置；落盘失败保留旧配置。字段无效或存在缺失正文的恢复文件明确拒绝。读取队伍快照不在本账号锁内申请其他账号锁；投影绑定owner、选角epoch、实例及配置revision。进图、返城、队伍变化和后续命令刷新，包括保活触发到期清理。

职业组队和回归Buff使用原生NOTI487添加和488删除。职业组队击杀经验从 `etc/variousbufflist.etc` 的 `hunter_exp_rate` 读取，当前1087/1088/1089分别为20%/50%/100%，1273没有击杀经验加成。

四叶草本人按独立资源获得击杀10%、通关15%、任务10%经验；同一正式副本内的其他幸运队友带来通关10%奖励，多人不叠倍。各来源独立向下取整、沿原成长事务实际落库，NOTI37显示与基础扣除守恒，结果页+123/+131分别显示幸运本人及队伍通关分项。幸运职业可通过原生562选择燃烧，比例来自同一资源当前100%，沿既有疲劳扣费和入场冻结规则；不赠送网吧身份，与网吧资格并存时取较高比例。职业变化停止后续燃烧资格，保留玩家已保存的开关选择。

有效回归账号下发NOTI1761的16B原生身份：`u32 type=1, u16 shown=1, u16 welcome, u16 daily, u16 reserved=0, u32 expiresUnix`。welcome/daily为1可领取、2已领取；shown只表示引导已展示。+12是绝对到期时间。普通/到期清空为16个0，首次普通账号不额外发无效通知。

回归任务读取同一资源的36条任务声明，NOTI1762固定100个`id:u32, progress:u32, state:u32`槽，尾部空槽为零。state为0未完成、1可领奖、2已领奖。等级门槛、条件列表、累计次数及奖励保留资源定义；真实技能保存、任务交付和正式通关在原业务事务中累计，公会、等级、已完成任务、换装及抗魔条件按当前角色事实观察。零通关经验的合法副本仍正常推进任务；结算重放不重复累计。客户端观察请求不能伪造副本或剧情完成。

CMD1734严格读取`action:u32, argument:u32`，欢迎奖励为1/0、每日奖励为3/0、任务奖励为4/任务编号；原生应答为12个零字节，随后刷新1761/1762，不能套用普通成功字节。身份1只发回归欢迎奖励，不混发资源中的新手奖励。奖励通过现有背包规划及同一角色仓储提交，账号周期领取账本与资产、revision处于同一事务。背包满、过期、过期owner或旧revision不消耗资格；重复请求、账号换角和重开数据库不重复发放。每日奖励沿现有服务日切换，不重置欢迎及任务奖励。迁移205仅追加空进度及领取账本，不补造旧完成事实。

GM命令和范围见[开发GM](../开发/GM.md#职业幸运与回归账号)。`AdventurerBenefitTests`覆盖资源、人数/职业、期限、持久恢复及写失败；`ReturningAdventurerTests`覆盖原生任务/领奖合同、背包与账本原子性、重复、满包、跨日和到期；数据库定向覆盖v204升级、冲突及末段回滚、较新版本拒绝。`adventurer-benefits` TCP组覆盖实际GM、原生身份/任务/领奖、组队Buff、真实击杀到账、过期与离队清理。定向自动化检查不等于游戏视觉或所有回归活动玩法已验收。

新回归系统的头像身份同时通过Actor尾部既有u16传递：026788CF读取、026788D8安装到角色Data+418，02D83A20供`Interface2/ReturnSystem/System_new_return.img`绘制使用。有效回归账号为1，普通或到期为0；它独立于旧活动state46和`return_party_cn.img`。所有本人、同屏、队伍、攻坚队及角色外观刷新都传递同一身份。GM设置及期限变化沿后续命令刷新同屏Actor和队伍名册，不重发战斗Player、属性或主机。公开快照的发送资格检查身份是否仍有效，避免到期或设置变化后发送旧身份。

幸运名单的投影绑定当前owner、选角epoch和配置，职业覆盖变化及日程到期后拒绝发送旧名单。自动化覆盖名单金样、合法成长分支、GM在线刷新、资格变化、经验实际到账及燃烧开关；四叶草图标和客户端技能面板效果仍须游戏内验收。
