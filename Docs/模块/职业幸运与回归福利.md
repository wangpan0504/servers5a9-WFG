# 职业幸运与回归福利

职业活动读取当前PVF的 `event/partybuffeventasjob.evt`，按基础职业、转职及队伍内匹配人数选择原生Buff；没有个人“幸运角色”标志。默认资源目标为女格斗全部转职，1/2/3/4名匹配成员分别对应队友1087/1088/1089/1089。活动职业本人使用独立的 `[party job buff info]`，当前为空，因此不额外获得队友专属Buff。GM覆盖目标基础职业后，适用于全服该职业全部转职，仍使用原资源队友档位；原Buff名“女格斗家的得力队友”不被改写。

回归资格按账号保存，福利期限来自 `event/chn_event/200114_newreturnsystem/chn_returnsystem.evt` 的 `[benefit period]`，当前28天。`chn_event_returnsystem.evt` 的返回者/现役队友Buff当前均为1273；至少两人处于同一正式副本且有有效回归账号时，分别给双方对应Buff，同索引不重复。资格到期、返城或队友离开后重新计算并清理。账号资格由GM设置，不复用旧角色JSON的 `LegacyReturningPlayer`。本模块不推断自然离线天数，也不实现回归任务、签到或礼包领取。

`AdventurerBenefitStore` 在 `Data/adventurer-benefits.json` 持久保存目标职业覆盖值及账号绝对期限，先Flush并原子替换文件，再发布不可变配置；落盘失败保留旧配置。字段无效或存在缺失正文的恢复文件明确拒绝。读取队伍快照不在本账号锁内申请其他账号锁；投影绑定owner、选角epoch、实例及配置revision。进图、返城、队伍变化和后续命令刷新，包括保活触发到期清理。

Buff使用原生NOTI487添加和488删除。击杀经验从同一 `etc/variousbufflist.etc` 的 `hunter_exp_rate` 读取并实际加入成长事务，NOTI37的Buff分项和落库总量一致；不加成任务或通关经验，不重复已有Buff分项。当前1087/1088/1089分别为20%/50%/100%，1273没有击杀经验加成。

有效回归账号下发NOTI1761的16B原生身份：`u32 type=1, u16 shown=1, u16 0, u32 0, u32 expiresUnix`；普通/到期清空为16个0。shown仅表示首次引导已展示，不能理解为领取奖励。+12是绝对到期时间；不发送未知状态字段或伪造奖励成功。首次普通账号不额外发无效通知，曾有效后到期会清除。协议字段由匹配客户端00498680/00498290/00498160消费链确认；客户端实际标识、技能及属性面板仍须实机验收。

GM命令和范围见[开发GM](../开发/GM.md#职业幸运与回归账号)。`AdventurerBenefitTests`覆盖资源、人数/职业、期限、持久恢复及写失败；`adventurer-benefits` TCP组覆盖实际GM、原生身份、组队Buff、真实击杀到账、过期与离队清理。定向自动化检查不等于游戏视觉或所有回归活动玩法已验收。

新回归系统的头像身份同时通过Actor尾部既有u16传递：026788CF读取、026788D8安装到角色Data+418，02D83A20供`Interface2/ReturnSystem/System_new_return.img`绘制使用。有效回归账号为1，普通或到期为0；它独立于旧活动state46和`return_party_cn.img`。所有本人、同屏、队伍、攻坚队及角色外观刷新都传递同一身份。GM设置及期限变化沿后续命令刷新同屏Actor和队伍名册，不重发战斗Player、属性或主机。公开快照的发送资格检查身份是否仍有效，避免到期或设置变化后发送旧身份。

上述职业组队活动与原生幸运角色是两套机制。`etc/loadingadvermessage.etc`另有幸运角色本人15%通关经验、队友10%通关经验及免费燃烧疲劳的声明；当前职业活动实现尚不能作为该幸运机制或四叶草图标已完成的依据。
