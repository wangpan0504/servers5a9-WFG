# 新版冒险团

本模块提供账号冒险团的基础进度、显示名称、轻量角色收藏、代表角色与远征；协议见[冒险团协议](../协议/冒险团.md)。基础资源由[AdventureCatalog](../../Server/DfoServer/GameWorld/Adventure/AdventureCatalog.cs)读取本版`etc/adventurersystem/adventurersystem2018.etc`，远征由[独立目录](../../Server/DfoServer/GameWorld/Adventure/AdventureExpeditionCatalog.cs)读取`adventurerexpeditionsystem.etc`，二者共享原PVF归档，不读取旧linksystem配对。

## 所有权与初始化

[账号状态](../../Server/DfoServer/Game/Adventure/AdventureState.cs)从Lv1、经验0和零余额开始。名称缺省为账号前16字符，独立保存与回放，不参与认证。已有名称、创建日期及进度不会因重登、查询或存量高等级角色被重置，不补发历史经验、奖励或胶囊。当前代码没有客户端起名/改名处理器，不能将数据库中名称可保存误称为已实现客户端起名。

认证成功并取得owner后，在CharacterSelect阶段初始化缺失账号行；已有行只读检查，不取得writer。基础查询采用一致只读事务，只读取本账号进度及角色身份、职业、等级、熟练与revision，不装载其他角色的完整背包或技能，也不建立平行在线角色表。所有调用沿原AccountOwners generation；会造成角色上下文变化的选角仍由GameSession管理。

登录端点和名册后不主动盲发冒险团。空C2S645确认选角上下文后，先ACK645 `01 00`，再发送actor0的1343；此时不发依赖实体的1349、不选择角色，也不设置Ready。C2S1403在选角阶段只允许target0，入城后只允许0/本人；其他目标失败，不能读取其他账号。查询和零变化不切状态。

入城完成原角色、资产和称号初始化后，再对实际Actor发送1343/1349，继续原城镇绑定及Ready边界。返回选角保持同一owner、推进原选角epoch，下一次645重新回放账号信息。异步发布核对原epoch及角色引用，旧角色或接管后的结果不能覆盖新上下文。

## 角色收藏与边界

职业分类、第五转职及满级/二觉资格取本版资源。默认展示名册首个合法同职业候选；记录使用本账号真实角色身份，不把UI排序槽作为UID。外传CHR分支0只在此领域转换为资源分类1，不改角色或技能树。

账号基础状态保存在`account_adventures`基础表，以v29接续现有v28，保持所有任务、称号、训练、键位、心情、掉落及资产表。完整7440B信息保留五类结晶、购买计数、职业计数和胶囊字段；购买计数来自实际提交的账号限购状态，查询不发占位成功。

代表候选、设置和解除已接入1476/1477/1478。候选仅来自本账号当前符合资源的角色，设置绑定真实角色UID；同职业没有显式选择时显示首个合法候选，解除保存NULL职业格，使重连不重新恢复默认角色。角色职业、等级或名册revision在规划后变化会使原提交失效，不用旧候选覆盖新状态。

代表与账号revision同一事务提交；插入失败回滚全部绑定与版本，已存在的相同设置/解除按合法零变化只读验证，不取得writer或重复增加版本。v30在基础v29后追加代表表，不修改原账号进度和角色资产。删除被选代表的角色时，原事务将对应职业格来源置NULL并推进账号版本，不清空整个冒险团。发布使用本次实际提交的收藏记录，先专用ACK，再1343/1349同步，保持原user/细阶段。

## 远征

441支持选角期和已就绪角色查询，始终包含area0空闲代表组。442按资源地区、冒险团等级、时长和1至4名合法代表出发；客户端selector只用于本次名册匹配，数据库绑定本账号真实UID。远征冻结成员名称、职业、等级、selector、地区属性、奖励和结束时间，后续月轮换或换角不重算原奖励。运行中的代表不可更换或解除，返回已核验忙碌错误227。

1407取消不授奖，1408只允许到期领取。领取将资源倍率的float32结果先四舍五入，再乘extra rate并截断，结晶、远征删除、成员释放与唯一凭据同事务提交；SQL失败整笔回滚，重复领取不再发放。v31追加远征、冻结成员及账号凭据表，保留v30的代表及原账号进度。结晶月重置按UTC+8与资源声明只读投影，下一次实际写入保存，不为查询取得writer。

远征成员尚未取消或领取时拒绝删除角色，原事务再次复验成员身份；不通过删除角色释放未结算远征。成员已释放后允许删除，代表来源置NULL并保留职业格，历史账号凭据只将来源置NULL，不删除操作身份、进度或已发奖励。

代表变更先专用ACK，再1345刷新空闲成员及1343/1349同步账号；远征出发先ACK再1345，取消和领取再追加账号信息。发布使用实际提交快照并核对owner、epoch、细阶段和副本身份，不重建Actor或切场景。

## 商店

1414按资源类别、PVF声明顺序、等级、结晶费用和限购处理，一次发放一件；选择值接受该类别原序号及物品ID，不用排序后的目录下标。发放复用现有完整物品、钱包及史诗碎片规则，保留堆叠、容量、期限和实例属性。允许在现有可操作城镇、副本及结算上下文购买，不收窄副本内请求。

扣结晶、限购、实际物品UID、账号revision及审计同事务；晚期SQL错误全部回滚，不提前应答成功。v32在远征v31后只追加账号限购表，不重建已发布结构或补历史购买。商品重置类型3按UTC+8月边界只读投影，下一次实际账号写入同时保存月份、结晶与旧限购清理；代表或远征写入也不能只推进月份而漏掉限购。

先专用ACK，再从实际提交角色投影物品差量，最后1343/1349同步账号。旧owner、epoch、角色引用和场景结果不发布。

## 成长胶囊

1499空请求消费已有账号胶囊进度，仅限城镇，等级上下限、每次消耗及获得经验取当前资源。它不复用角色级`CharacterDungeonState.GrowthCapsuleExperience`；后者是另一业务的附属字段。缺合法双技能树、角色附属owner或不足进度时不扣除，不根据历史资源日期清空进度。当前未接入击杀、通关等账号经验累计，不能将领取能力误称为已经自动生产胶囊。

账号扣除、角色绝对XP、两树成长、相关任务条件及凭据同事务，失败整笔回滚；领取的经验不递归返还账号结晶、等级或胶囊。此功能不新增库表。提交后先ACK，再完整37、必要技能绑定、既有等级/任务刷新，最后1343/1349同步账号与实体，核对原generation、epoch和实际角色引用，不切场景或恢复旧快照。

[远征核心回归](../../Server/DfoServer/SelfTests/AdventureExpeditionTests.cs)覆盖冻结、公式、忙碌资格、唯一领取、月重置、真实SQL失败及v23增量回滚；`--selftest-tcp adventure-expeditions`覆盖查询、出发、取消、到期领取、重放和重启恢复。

[购买核心回归](../../Server/DfoServer/SelfTests/AdventureShopTests.cs)覆盖购买计数字节、只读周期、真实SQL晚期失败、实际UID与v24升级；`--selftest-tcp adventure-shop`验证原生序号购买、余额/限购拒绝、全事务回滚及跨进程恢复。

`--selftest-tcp adventure-capsules`复用公共只读资源，先验证[资源与SQLite用例](../../Server/DfoServer/SelfTests/AdventureCapsuleTests.cs)的上下限、未知成长拒绝、双树保留、晚期SQL回滚与重开，再验证账号换角、专用1499/37包序、重复请求和进程恢复。客户端领取动画、升级和窗口仍需实机验收。
