# 新版冒险团

本模块提供账号冒险团的基础进度、显示名称、轻量角色收藏、代表角色与远征；协议见[冒险团协议](../协议/冒险团.md)。基础资源由[AdventureCatalog](../../Server/DfoServer/GameWorld/Adventure/AdventureCatalog.cs)读取本版`etc/adventurersystem/adventurersystem2018.etc`，远征由[独立目录](../../Server/DfoServer/GameWorld/Adventure/AdventureExpeditionCatalog.cs)读取`adventurerexpeditionsystem.etc`，二者共享原PVF归档，不读取旧linksystem配对。

## 所有权与初始化

[账号状态](../../Server/DfoServer/Game/Adventure/AdventureState.cs)从Lv1、经验0和零余额开始。账号前16字符只作未命名账户的持久回退名称，不参与认证。新账户的首次命名资格独立保存，1375空名进入本版起名窗口；旧账户保留原名并视为已命名，不自动给予免费改名。已有名称、创建日期及进度不会因重登、查询或存量高等级角色被重置，不补发历史经验、奖励或胶囊。

认证成功并取得owner后，在CharacterSelect阶段初始化缺失账号行；已有行只读检查，不取得writer。基础查询采用一致只读事务，只读取本账号进度及角色身份、职业、等级、熟练与revision，不装载其他角色的完整背包或技能，也不建立平行在线角色表。所有调用沿原AccountOwners generation；会造成角色上下文变化的选角仍由GameSession管理。

登录端点和名册后不主动盲发冒险团。空C2S645确认选角上下文后，先ACK645 `01 00`，再发送1375账号显示名称和actor0的1343；此时不发依赖实体的1349、不选择角色，也不设置Ready。1375与1343使用同一账号快照；1375在首次命名资格尚未消费时发送空名，其余回放持久名，独立初始化客户端账号名称上下文，不能仅凭1343已带名称就省略。C2S1403在选角阶段只允许target0，入城后只允许0/本人；其他目标失败，不能读取其他账号。查询和零变化不切状态。

入城完成原角色、资产和称号初始化后，依次发送1375及实际Actor的1343/1349，继续原城镇绑定及Ready边界。返回选角保持同一owner、推进原选角epoch，下一次645重新回放账号名称和信息。异步发布核对原epoch及角色引用，旧角色或接管后的结果不能覆盖新上下文。

## 命名与改名

[名称用例](../../Server/DfoServer/Game/Adventure/AdventureNames.cs)接入1438首次命名、1444重名检查和1445改名券。名称允许CP936可表示的字母、数字与下划线，最多16字符/32B；不接受空白、控制字符及额外协议字节。重名检查只查询账号名称索引，不加载其他账号的完整资产，不取得writer；ASCII大小写不区分，允许检查本账号原名。实际提交再次占用同一SQLite writer并复验名称，不能以预检查成功代替跨账号唯一性。旧库已有重名原样保留，新命名和改名不能新增重名。

1438只消费一次持久首次资格，成功回原生名称正文并刷新1375/1343，入城时另有1349。相同名字的重放不再写revision；已命名账户不能用1438换成另一个名字。首次命名允许选角和已就绪城镇，保持原user状态，不隐式选角色或消耗资产。

头顶昵称另由Actor记录的独立字段承载，不能以1375或1343含有名称代替。入城及换装、心情、等级和职业的Actor刷新都读取本账号已提交名称；未命名账户保持空昵称。城镇首次命名还刷新当前Actor和同屏成员，不清场或切user状态。同屏昵称归原成员的投影快照，加入及刷新前从原owner取得，不在成员锁内查询数据库，也不借用接收者名称。姓名投影只查账号名称与首次标志，不装载冒险团名册、进度或其他角色资产。

本版Actor昵称字段仅容纳16个CP936字节和终止NUL；较长名称按完整字符投影前缀，不拆开双字节字符或覆盖紧邻字段。持久名称和1375/1343仍保留完整16字符/32B合同，不因窄头顶字段收窄合法命名；线格式及绘制消费者见[冒险团协议](../协议/冒险团.md)。

1445模式0要求城镇、真实Main槽的完整未过期消耗品及已确认的`[represent account name change]`动作。原生资源还要求`[waste]0`、all职业、等级范围和village/dont use assult场景声明；安全锁拒绝，排序锁不扩大成禁用。当前没有街头争霸或攻坚队上下文，活动门禁仍生效。模式1的免费改名权益未装配，拒绝请求，不因客户端的模式值或255槽号授予资格。

名称、首次资格、券消费、账号周期和审计同事务；SQL或后段审计失败整笔回滚，不提前成功，发送失败不重跑扣券。相同名称保持合法零变化，但仍检查券和状态资格。成功改名先专用ACK，源槽1681无获得提示差量及1375，再复用已有ACK7/名册返回选角链；Session同步解除原角色、城镇成员和原epoch，保留账号owner，不能让客户端已回选角而服务端仍为Town。再次选角和重启从实际提交名称及资产恢复。

v38只追加首次命名标志和查询索引，旧名称、账号revision、角色资产与冒险团进度保留。命名规则和持久化不重用角色12B姓名限制，不按昵称判定认证或角色归属。查询他人冒险团、按名称找在线角色以及冒险团密语未接入，不返回占位成功。

## 角色收藏与边界

职业分类、第五转职及满级/二觉资格取本版资源。默认展示名册首个合法同职业候选；记录使用本账号真实角色身份，不把UI排序槽作为UID。外传CHR分支0只在此领域转换为资源分类1，不改角色或技能树。

账号基础状态保存在`account_adventures`基础表，以v29接续现有v28，保持所有任务、称号、训练、键位、心情、掉落及资产表。完整7440B信息保留五类结晶、购买计数、职业计数和胶囊字段；购买计数来自实际提交的账号限购状态，查询不发占位成功。

代表候选、设置和解除已接入1476/1477/1478。候选仅来自本账号当前符合资源的角色，设置绑定真实角色UID；同职业没有显式选择时显示首个合法候选，解除保存NULL职业格，使重连不重新恢复默认角色。角色职业、等级或名册revision在规划后变化会使原提交失效，不用旧候选覆盖新状态。

代表与账号revision同一事务提交；插入失败回滚全部绑定与版本，已存在的相同设置/解除按合法零变化只读验证，不取得writer或重复增加版本。v30在基础v29后追加代表表，不修改原账号进度和角色资产。删除被选代表的角色时，原事务将对应职业格来源置NULL并推进账号版本，不清空整个冒险团。发布使用本次实际提交的收藏记录，先专用ACK，再1343/1349同步，保持原user/细阶段。

## 远征

441支持选角期和已就绪角色查询，始终包含area0空闲代表组。442按资源地区、冒险团等级、时长和1至4名合法代表出发；客户端selector只用于本次名册匹配，数据库绑定本账号真实UID。远征冻结成员名称、职业、等级、selector、地区属性、奖励和结束时间，后续月轮换或换角不重算原奖励。运行中的代表不可更换或解除，返回已核验忙碌错误227。

原生客户端可以发送成员数为0的完整442请求。该请求由业务层拒绝，不创建远征或增加账号revision，并保持连接可继续查询；不能把没有选择成员视为包结构异常。缺失成员行、额外字节和超过协议容量的请求仍按Parser边界拒绝。

1407取消不授奖，1408只允许到期领取。领取将资源倍率的float32结果先四舍五入，再乘extra rate并截断，结晶、远征删除、成员释放与唯一凭据同事务提交；SQL失败整笔回滚，重复领取不再发放。v31追加远征、冻结成员及账号凭据表，保留v30的代表及原账号进度。结晶月重置按UTC+8与资源声明只读投影，下一次实际写入保存，不为查询取得writer。

远征成员尚未取消或领取时拒绝删除角色，原事务再次复验成员身份；不通过删除角色释放未结算远征。成员已释放后允许删除，代表来源置NULL并保留职业格，历史账号凭据只将来源置NULL，不删除操作身份、进度或已发奖励。

代表变更先专用ACK，再1345刷新空闲成员及1343/1349同步账号；远征出发先ACK再1345，取消和领取再追加账号信息。发布使用实际提交快照并核对owner、epoch、细阶段和副本身份，不重建Actor或切场景。

## 商店

1414按资源类别、PVF声明顺序、等级、结晶费用和限购处理，一次发放一件；选择值接受该类别原序号及物品ID，不用排序后的目录下标。发放复用现有完整物品、钱包及史诗碎片规则，保留堆叠、容量、期限和实例属性。允许在现有可操作城镇、副本及结算上下文购买，不收窄副本内请求。

扣结晶、限购、实际物品UID、账号revision及审计同事务；晚期SQL错误全部回滚，不提前应答成功。v32在远征v31后只追加账号限购表，不重建已发布结构或补历史购买。商品重置类型3按UTC+8月边界只读投影，下一次实际账号写入同时保存月份、结晶与旧限购清理；代表或远征写入也不能只推进月份而漏掉限购。

先专用ACK，再从实际提交角色投影物品差量，最后1343/1349同步账号。旧owner、epoch、角色引用和场景结果不发布。

## 等级经验与满级溢出

角色达到本版上限95级后，通关结算的整单经验不再进入角色经验条，而是作为溢出在同一结算事务内推进账号冒险团：账号经验按资源`[adventure exp rate]`折算，小数部分保存在`remainder`并跨结算累计，再按`[adventure exp table]`逐级扣除边界直到资源满级；同一份溢出同时按`[exp to get shop point]`兑换勇者结晶点数（按`[max shop point]`封顶、余数保留），并按胶囊容量封顶累计成长胶囊进度。跨过95级入口线的单笔结算只取入口线以上的差额；未满级、教程或零经验的结算不读写账号冒险团。

账号快照、增量规划与结算提交在同一事务：业务层在账号锁内读取规划快照，仓储在事务内重读并核对快照，再按同一规则重算提交后状态；版本失配、伪造增量或任一SQL失败整笔回滚，不留下角色经验、receipt或半份账号进度。重复通关报告只读已提交receipt，不重复发放。当前只接入满级通关溢出；击杀、任务等其他经验来源尚未接入。

## 成长胶囊

1499空请求消费已有账号胶囊进度，仅限城镇，等级上下限、每次消耗及获得经验取当前资源。它不复用角色级`CharacterDungeonState.GrowthCapsuleExperience`；后者是另一业务的附属字段。缺合法双技能树、角色附属owner或不足进度时不扣除，不根据历史资源日期清空进度。胶囊进度只来自满级通关溢出（见上一节），击杀、任务等其他经验来源尚未接入；不能把领取能力误称为全部来源已自动生产。

账号扣除、角色绝对XP、两树成长、相关任务条件及凭据同事务，失败整笔回滚；领取的经验不递归返还账号结晶、等级或胶囊。此功能不新增库表。提交后先ACK，再完整37、必要技能绑定、既有等级/任务刷新，最后1343/1349同步账号与实体，核对原generation、epoch和实际角色引用，不切场景或恢复旧快照。
