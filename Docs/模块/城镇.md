# 全城镇通行

本页定义当前匹配PVF的城镇准入、码头与房间传送阵合同。wire格式及发包顺序见[城镇切图](../协议/城镇切图.md)，会话/持久化规则见[服务端业务开发规范](../规范/服务端架构.md)。

选角、普通切图、出房及副本回城统一从本次角色快照投影转职特效显示位，各职业沿用同一合同。开启和关闭均保留角色设置，不因换区清零，也不额外重发完整入城或设置通知。

入城的保护压缩EVENT_INFO使用完整事件表：保留赛丽亚2037、完整2037尾表与当前团本开放事件；已提交的2532显式常驻状态开启时追加2532，关闭或auto时移除，64黄金牌状态不进入此表。ServerEventService由Runtime创建并与开发命令共用，入城读取不写库或增加revision。2532未配置默认关闭，不能由历史日期、角色等级或64开关推定开启。

服务端状态持久化与完整封包不代替客户端验收；诺兰正常活动入口、关闭后的显隐及生命周期、31B截断拒绝和无部分状态仍需匹配客户端证据。

星河裂缝10005只在显式装配的资源可用且活动开关开启时进入同一完整108目录；资源可用参数缺省为false，缺少活动服务也不显示。266和10005共用每连接一个活动投影worker、容量1唤醒队列及选角epoch守卫，开关与各自时间表边界刷新整表，不移除其它目录或设计页。10005当前只追加目录记录，不猜测专属数值尾块；目录投影不代替副本准入、奖励或客户端入口验收。

## 1. 资源和实现入口

服务端启动从 `Data/Pvf/Script.pvf` 读取实际城镇、区域与默认/阶段地图，不限制到最初房间区域，也不依赖预导出JSON。既有资源样本包含65个城镇、343个区域、去重352份地图，这些数量不作为启动校验条件。

## 2. 准入与位置

C2S36固定16B，完整保留targetNpc:u32、pathKind:u8、x/y:u16。Parser要求movement=5，pathKind允许0–255；“能解析所有字节值”不等于“所有特殊玩法已实现”。

`GameSession.Travel` 在当前 owner 内检查就绪阶段；[TownTravel](../../Server/DfoServer/Game/Town/TownTravel.cs) 从角色快照、请求和完成任务集合规划移动、切图与无坐标出房。它核对 previousTown/previousArea 等于原 Position，再由 TownCatalog.Admission 按以下顺序判断：

1. 目的地区域存在且当前阶段地图可用，目标等级、need quest全部完成、need quest or至少一项、except quest均不命中。
2. targetNpc非零时验证来源NPC的显式传送关系与目标地图NPC身份。
3. 房间右侧菜单验证配置目的地及菜单等级/任务；已观测kind5走菜单，其他kind在目的地确实属于菜单时也按同一配置判断。
4. 普通房间出口必须匹配持久返回地区。例外：共享房间38/1所在城镇以外的房间式区域（如艾尔丁纪念馆67/0）自己的地图写有通往本城非房间区域的门时，这扇门按第6条普通通路判断。
5. 非房间来源的码头间传送验证当前开放阶段与两端权限。
6. 其他普通通路必须存在PVF有向出边；要求相关任务完成，非空check condition目前返回route-state-required。

普通超时空之战和漩涡团队独立：普通频道type22从艾尔文38/0的天界支援兵400000040传送到115/0的400000041，再进入115/1选择普通副本400000016；漩涡type45使用57/0门厅，共享房间出门直达57/1招募NPC624。57仅允许type45，115仅允许普通频道；通用副本入口同时核对两种玩法授权，不能用伪造切图或选图请求跨玩法进入。历史115或战场位置在漩涡重选时回共享房间，原团重返由原实例恢复。

安徒恩19/2、卢克32/4、普雷59/2和漩涡57/2及后续战场仅属于攻坚实例，不作为选角或换频道可恢复的普通城镇快照。重登先进入目标频道的正常入口；有效835/668重返继续由原实例恢复，不删除重返资格。候战区内移动保留进入前的普通返回地区；旧存档误记的候战区Return在选角时修复。卢克32/3同时用于普通街区与团队入口：type32内进出32/0房间、32/3入口和32/4候战区均保留普通返回地区，换频道选角使用来源频道类型；进程历史丢失时保留已独立记住的其他普通地区。普通频道的合法32/3返回记忆继续有效，不把整个城镇32判为攻坚实例。团队地区房间使用本地门出入，不把保留的普通返回地区当作本地出门目标。

## 3. 地图继承、阶段和返回地区

map import递归读取，局部几何区块替代父区块，显式空区块也替代。普通town movable area与动画move town共同形成有向出口；负数town/area标记不转换成普通byte城镇。几何行的quest condition约束任务，check condition保留为未接入实例条件。

阶段只使用completed quest，按最后满足的phase shift选择map；活动驱动阶段仍使用PVF默认图，不伪造活动开启状态。例如黑市完成5936使用Before阶段、完成6045使用Liberation阶段。

黑市的正式街道及小地图区域为54/1，54/0只引用固定Before地图，不作为房间返回地区。旧存档的位置或返回点为54/0时，正常重新选角沿已有返回地区解析，在等级与任务准入通过后使用54/1的当前阶段门口；不批量改库、不跳过5936等前置，也不改写正在进行的换频道场景快照。

哈林两个频道分组的候选落点同样使用54/1。完成6356后，NPC611的外观身份变为乔斯拉100000175；该身份只放置在6045完成后的Liberation地图，固定Before地图没有对应NPC。返回黑市时必须保留真实任务完成位并使用当前阶段街道，不能靠补发NPC或伪造任务修复。旧存档重选与1426出房的23/24、1379及完成表由城镇TCP回归覆盖；NPC画面仍需匹配客户端验收。

通过Common/Gate_Seria.map及其(r)版本继承识别房间。共享房间38/1记住最后可用地区，街道返回点也保留；进入无房间的NPC特殊区保持此前地区。普通频道（`channel.txt` type 22）的共享房间出口只认持久返回地区，频道分组不改变出门城镇，在哪个城镇下线就回哪个城镇；只有特殊区域与团队频道按频道落点出门，见[帧与频道](../协议/帧与频道.md)。只经频道进入的城镇（ChannelAreaLanding.IsChannelBoundTown，如艾尔丁纪念馆67）与频道起始城镇安徒恩战舰19、帝国竞技场48及再战魔界62（ChannelAreaLanding.PreservesRoomReturn）内切图保持进入前的返回地区，战舰街区不写入共享房间的返回地区；旧存档若已把战舰19/1记成返回地区，普通频道选角与频道重连按共享房间初始地区修复，位置不变。进入房间时保存来源地区门口，选角统一出生450,234，空body1426返回对应地区门口。默认艾尔文防线返回622,196，不能使用离线站立坐标代替。

## 6. 药剂与光环个人传送

瞬移药剂的`minimum level`是可选声明，缺失时与堆叠模板一致按0解释；显式空值、负值、多个值或超出本服等级上限仍拒绝。缺省等级不取消原有冷却、位置、任务与库存资格。

## 状态与拒绝语义

旅行规则只返回目标位置、返回地区和拒绝原因，不写库或修改 Session。[会话协调](../../Server/DfoServer/Game/Session/GameSession.Town.cs)在原 lease 内调用规则与提交，`CharacterRepository.Save` 用 `id + account + expected revision` 更新位置和返回地区，恰好影响一行后提交，revision 加1。Session 安装实际返回角色，并给调用方 `TownTravelReceipt`（角色、generation、选角 epoch）。步行位置（含朝向）未变不重复保存，速度不参与位置值；旅行普通拒绝无成功回执，不修改存档、不增加 revision、不关闭连接。

投影使用本次回执中的位置构造 23/24/可选1379，不在清场等待后重新读取另一份 Selected。清场前、每帧发送前和加入新场景前重新核对原会话与角色；另一选角 epoch 的旧结果跳过，不能移除或加入新角色成员。同次选角中快照被 GM 或其他提交替换时，关闭原连接，让重登恢复已提交位置，不能丢掉必要切图通知后继续处理请求。发送失败不回滚旅行、不重跑保存。已经开始的网络写入仍可能与状态变化交叠，门禁不能撤回在途帧。结构错误、过期 owner 或 SQL 异常也由连接生命周期记录后关闭。

无资源的[规则与选角测试](../../Server/DfoServer/SelfTests/TownSelectionTests.cs)覆盖全部 kind 字节、权限/阶段、NPC 优先级、坐标、事务与回执边界；[旅行发布测试](../../Server/DfoServer/SelfTests/TownTravelPublicationTests.cs)使用真实 Handler/发送队列，覆盖清场等待与首帧写入期间的重选、同 revision GM 更新和实际包序。测试入口见[贡献指南](../../CONTRIBUTING.md#验证)。

同区域36返回 `same-area`；未知NPC、无PVF出边、任务/等级不满足、需要实例状态等都有独立Reason。未恢复的错误ACK不由服务端猜造。新业务若客户端会进入等待状态，必须先恢复匹配版本的失败收尾合同，再接入请求。
