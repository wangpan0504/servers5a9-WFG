# 角色属性

角色属性来源属于 GameWorld；在线角色、等级、学习树、装备槽和 revision 仍由 Session 的实际 Selected 快照持有，不建立第二套在线属性状态。完整物品实例继续由[背包与装备](背包与装备.md)保存；经验、等级和两树 SP 的事务见[角色成长](角色成长.md)。

`CharacterCatalog.GetAttributeDefinition(job)` 装载 job0–15 的原始 CHR 属性声明。`CharacterAttributeDefinition` 分开 initial、各 growtype 及其 awakening，保留 float32 数值、负声明和缺项；资源编号本身不作为业务 GrowType 的映射。

独立的 [CharacterStatComputer](../../Server/DfoServer/Game/Characters/CharacterStatComputer.cs) 属于 Game 层，通过共享的 `CharacterCatalog` 读取资源；资源定义和目录只负责解析、保存声明与查询，不承担等级属性计算。`ComputeLevelBaseStats(job,growType,level)`提供全部16职业及目录内转职/两觉编码Lv1..95的正常CHR基础成长：每项先转换为原生十倍整数，初始值加未转职块乘`min(L,18)-1`，再加实际firstGrow块乘`max(L-18,0)`。正常模式基础沿V31匹配原码，不把旧版50级觉醒分段或技能/永久修正合并进CHR。客户端另有永久/模式修正、装备效果应用和能力缓存重算，不能将服务端计算的装备总额直接叠进89B。当前目录没有提供强化、附魔、增幅、精通、被动的全部最终属性规则；因此正常升级和穿脱的面板、战斗属性一致性尚不能从服务端基础字节或装备列表推出。资源与wire的证据边界见[属性声明与消费](../资源/角色属性.md)。

`CharacterStatComputer.Compute(character)`从实际角色快照评估本人Player属性，统一判断来源资格：job0–15、CHR目录内合法成长编码、实际Lv1..95、完整两树Learning和非空DungeonState。创建用例明确初始化这两个owner；当前服务没有永久属性授予入口，普通角色基础切片只包含CHR成长。缺少附属owner的存量角色保留原InitialStats投影与存档，不补造来源或清未知字段。计算器无角色缓存或持久状态，只返回类型化 `CharacterStats`，不生成协议字节。发布仍使用原角色快照、Session当前选角epoch及提交回执资格，不另建带ID/revision的属性副本。

`ServerRuntime`显式创建一个计算器，供 `TownProjection`、`InventoryProjection` 和 `CharacterLevelProjection` 共享。三个入口在锁外以各自实际角色快照计算属性，再交给 `TownPackets.Player(character, attributes)`；Builder只将结果交由 `CharacterStatsPackets.Build` 编为89B，不查询资源或重新计算。计算器不读数据库、不发包，Projection继续负责包序和发布资格。当前实现不增加属性存档、数据库字段、接口转发或DI容器。

511精通在本地buff manager的最终能力buffer3阶段应用，174基础精通也修改最终buffer3攻击倍率分量；本人Player应继续提供完整装备Core和两树状态，以实际提交快照触发本地效果。服务端基础89B不再叠这些派生贡献。选角/重登及现有穿脱Actor→Player组使用计算器返回的实际等级基础。正式击杀、通关结算及3145领奖共用等级刷新入口，在完整N37和需要的N19之后、结算N35之前，实际升级时追加Player。副本/结算阶段按S4A21仅发Player，城镇/选图升级保留Actor→Player。通关用例在owner内返回真实调用前角色快照；重复已安装结算前后等级相同，不重复升级刷新。同等级XP增加不追加刷新。每帧仍核对原提交角色引用、generation、选角epoch及实例身份，发送失败不重复经验或奖励。普通模式HP和四个基础分量的完整getter/CHR安装桥仍需进一步证据，面板/战斗一致性仍待集中验收，不能由纯规则回归宣布全部属性功能完成。

[属性资源回归](../../Server/DfoServer/SelfTests/CharacterAttributeResourceTests.cs)覆盖资源块与觉醒归属、float32位精度、负值、缺项和非法声明，并核对全部16职业及合法转职/两觉编码Lv1/2/18/19/49/50/74/75/95的等级基础属性。回归验证基础数学、来源资格与通知，不替代客户端面板和战斗验收。
