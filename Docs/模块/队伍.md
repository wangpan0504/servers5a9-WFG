# 队伍

`Game/Party/PartyService`统一持有队伍身份、设置、邀请和四个成员槽位，单人创建与多人组队共用服务。Runtime 注入主线共享 `GameCache`，队伍及邀请各用独立索引；不建队伍数据库表或另一套在线目录。`GameSession`仍唯一持有角色、阶段、选角 epoch 和账号 owner。服务分配队伍 ID，`FFFF`为无队伍哨兵，不用队长角色 ID 代替。

## 创建、邀请与退出

城镇就绪角色可以创建队伍，只有队长可修改设置，容量1–4且不小于现有人数。原租赁、未决任务及交互占用门禁继续生效。重复同内容请求保留队伍对象；更新产生新快照，使旧名册失效。创建、修改与退队不写角色资产或 revision。

邀请绑定双方实际 Session、选角 epoch 和 owner generation，限不同账号、同频道、城镇阶段，双向黑名单均拒绝。复用既有 `AccountOwners.Lease.ExecuteTogether`，按账号名固定锁序校验双方；队伍锁内只校验和提交状态，不访问存储或等待网络。邀请30秒失效，同目标只保留一个待处理邀请；相同邀请重发幂等。回应复核邀请、容量与队长权限，重复接受已加入的同队只确认完成。无队伍玩家向已有队伍的队长发送请求也走此流程。

新成员占最小空槽。普通队员只能退出自己，队长可踢其他成员。离队保留队伍 ID 和幸存者槽位；队长退出后由剩余最小已占槽位接任，最后一人退出删除队伍。换角、断线及接管由协议生命周期精确移除原 Session，不能清理新会话成员。返回选角在ACK7前清理本人旧队伍模型，同时更新幸存者。发送泵再核对原身份、成员变更版本和队伍快照，旧 epoch/generation、旧清理或旧名册不发布。

手动委任只允许当前队长选择另一名当前城镇成员。获取双方 owner 后重新核对队伍快照、阶段与活动门禁；只变更队长及队伍版本，保留 ID、成员槽位、设置和连接。提交后原队长立即失去委任、设置及踢人权限，双方收到主机槽和成员增量；目录沿既有通知刷新。空槽、自身槽、越权或失效目标拒绝，不发送伪造成功。

## 城镇与队伍面板（快捷键 `]`）

`PartyProjection`在成员增减时先安装成员公开 Actor、实时百分比及实际 UDP 端点，再发送完整名册，随后安装最终对象的端点、城镇100%血蓝及队长主机槽。走门或传送重新绑定场景后，只给切区者恢复同一名册和血蓝，不重装队伍 Actor 或端点，不向静止队友重发入队投影；端点变化仍单独刷新实际端点。普通切区还必须保留客户端 Actor：旧区域收到新位置的 USER_AREA，本人由 AREA_USERS 重置地图，不能发送会清除队伍槽的 USER_LEAVE。USERINFO 对同 UID 可复用现存对象；对象先被删除再创建时，后续名册可能按新成员播放入队音效，因此不能将切区等同于成员增减。TCP 包序不证明音效及真实 P2P 握手结果，仍需匹配客户端验收。

`PartyDirectoryProjection`只保存本连接已经写出的列表基线，使用容量1的合并通知队列；连接退出时取消、等待工作者并解除订阅。未主动查询时，未组队观察者只收到同场景招募增量。队伍面板主动查询按同频道发现队伍，支持已确认的种类、未满员条件、标题/队长名关键词及分页；每页10条，一次至多三页缓存。普通频道默认实收 kind6 同时匹配 kind0 普通队伍。排序、反序、跨频道及其他招募选项语义尚未完整确认，当前按队伍 ID 排序并限制同频道，不宣称全部筛选生效。

同频道异区创建、切区后查询、队长移动及解散均刷新主动查询结果。异区只补目录引用的公开 Actor，本队成员沿用已有引用，不因打开面板或切区触发查询而重装；不发坐标或城镇入场，不创建虚假同屏实体。路由头不能授权查询另一个角色。选图隐藏招募行，回城恢复；空结果及超页响应保留真实总页数，避免客户端空页反复重查。

被动目录删除同样核对本轮捕获的队伍快照：成员变更已提交、通知尚未抵达的短暂区间，旧快照过滤失效不能被解释为队伍删除；等待下一次通知按新快照刷新。

## 副本与传送边界

当前只接通城镇多人组队；多人普通、任务与深渊实例待后续接入。多人选择副本明确返回不可用；Session 的普通选图、职业体验、教程选图及正式实例安装也拒绝多人，防止同队分别建立单人实例。单人及真实单成员队伍沿原副本流程。多人副本的独立掉落、结算与中途离队不提前记为完成。

组队光环仍只支持真实单成员队伍，核对唯一成员、队长及当前快照后沿独立434事务提交。规划期间退队、重建或修改设置使原授权失效，多人传送确认未接入。资格、冷却与回滚见[城镇](城镇.md#6-药剂与光环个人传送)。

## 验证入口

[SoloPartyTests](../../Server/DfoServer/SelfTests/SoloPartyTests.cs)、[SocialTests](../../Server/DfoServer/SelfTests/SocialTests.cs)及[玩家交互回归](../../Server/DfoServer/SelfTests/PlayerInteractionTests.cs)接入核心自测，覆盖请求边界、名册、重复/容量、委任权限、旧快照/目标失效及生命周期。[单成员 TCP](../../Server/DfoServer/SelfTests/Tcp/SoloPartyTcpTests.cs)保留创建、设置、退队与重选；[社交 TCP](../../Server/DfoServer/SelfTests/Tcp/SocialTcpTests.cs)覆盖双连接邀请、端点、切区恢复、委任与权限交接、踢人及目录创建/修改/异区查询。协议归[队伍协议](../协议/队伍.md)，自动化不代替客户端界面验收。
