# 怪物模拟战（阿拉德谋略战）

本模块使用 S5A9 / V31.0.24.0 的原生窗口991、活动2532及[怪物模拟战协议](../协议/怪物模拟战.md)。资源入口是 `event/gcontents/200114_monstermockbattle/monstermockbattle.evt`。客户端负责怪物 AI、动画和卡片属性演算；服务端保存账号卡册、分配战斗对象、核对当前实例死亡事件并结算真实资产。

## 开启与活动配置

资源存在时玩法默认开放，无需独立设置文件。活动管理2532显示为“阿拉德谋略战”，控制新卡册操作、新入场、诺兰NPC和商店；未配置及auto默认开启，显式off持久保留。关闭前已经入场的战斗仍可领取本局冻结的通关奖励。可选的`MonsterMockBattle/settings.json`只配置服务端特殊关卡日期映射，空对象`{}`沿用原版资源的绝对日历。

配置示例：

```json
{
  "SpecialCalendarStart": "2026-11-05"
}
```

玩法资料参考[官方活动介绍](https://dnf.qq.com/cp/a20200114version/page2-1.html)、[每日硬币说明](https://dnf.qq.com/cp/a20200114version/page2-3.html)及[官方奖励表](https://dnf.qq.com/cp/a20200114version/page3-1.html)。官方界面显示活力30/30，本服首次初始化给满30点；此前revision=1且零体力、空卡册及空进度的存档只补初始化一次。满额和超额停止恢复，低于30时每300秒恢复1点，离线累计并保留不足300秒的余量；时钟回拨不增加体力。出售仍拒绝且不删除卡片。召唤价格、五连折扣、合成费用、剧情与特殊关卡奖励从实际 EVT 读取。

怪物硬币490013685及召唤券490013680至490013684使用现有账号共通材料钱包。本服按用户指定规则，每日首次城镇就绪或在线跨日刷新时发100枚硬币；首次同样只领取当日100枚，换角、重连不重复，跳日不追补。每日、成就及通关的所有硬币奖励直接加入钱包，提交后同步563共通材料更新及1766余额；非硬币奖励仍通过15天邮件领取。谋略家印章490013686是奖励材料；活动体力独立保存。

活动2532的EVENT_INFO数值块第二项发送体力上限30，1766发送当前体力及到下一点恢复的秒数；恢复与日切复用原服务日唤醒。`SpecialCalendarStart`将服务端业务日映射到资源日程首日，业务日采用UTC+8的06:00。PVF保留原版绝对日历，客户端`0047C2B0`在当前日期未命中`[special dungeon info]`的2020绝对日历时固定回退`[+1E4]=20`（地下城18021）；服务端在未配置映射或当前日期超出2020日历时同样允许回退特殊关`world 20`准入。

首次引导保留原生raw2 bit1=0；实际成功召唤后置该位，后续打开不重复首次引导。原生教程第3步要求点击单次召唤，缺少独立guide03控件属于原版设计；当日到账的100硬币可直接用于该步。教程步骤在客户端进程内保存，1766不重置步骤，右上问号仍使用原生帮助。

硬币与EVT登记的召唤券共用已有活动材料背包投影：入城、换角及重连以13恢复list45，领取后14更新真实持有量，消费后1681静默扣减，耗尽清除原槽。563仍同步账号钱包；显示投影不复制资产、不创建普通背包物品或物理UID。仅发送563不会更新召唤界面的券数量。

## 卡册与对手

卡册按账号保存100格，最多上阵5张，双方各有9个阵位。支持单抽、五连、随机券与指定券召唤、同种同星合成、锁定、阵型保存、每星一次双选一属性及21项成就领取。出售暂不实现。锁定或上阵卡不能作为合成材料；合成保留目标卡的槽位、阵位、锁定及已选属性。

指定召唤的参数是该券奖池内的一基序号。普通抽取保留实际权重，不将零权重指定池转成随机池。成就包含召唤、剧情指定关、特殊关、PvP胜场、获得三至五星卡、获得使徒卡、25星编队及累计完成数；使徒身份取卡片资源分类。成就领取位、硬币直接入账及非硬币奖励邮件同事务保存。

获得画面的星级由召唤ACK的独立五项星级提供，逐项对应本次实际获得卡槽；先发送完整卡册，再以提交后的真实星级开启展示。单抽、五连、随机券和指定券使用同一规则，空位为FF/0，避免一星卡在获得画面误显示五星。

PvP匹配与搜索切磋暂不开放。资源与对手结构保留读取，C1736的匹配/搜索操作及C15/C16的mode2/3战场准入均拒绝。

## 战斗与奖励

资源提供20个剧情关、15个特殊关及匹配/搜索各5个战场。剧情逐关解锁，首次挑战免费；客户端`0047B8E0`将`0..20`共21项装入`[+208]`，`0073E2D0`对剧情模式末页“异次元裂缝”默认首关`world 20`（18021）直接按体力放行按钮，对其余轮换特殊关`21..26`才检查`[+21C]==20`（第20关已完成）与当日日程，服务端准入与之对齐。专用`C15`在建立选图上下文前同步校验活动准入，不满足条件时直接返回`ACK15=0`且不发送`27`，避免`00471690`连发`C15+C16`时因`C15`放行、`C16`被拒而将客户端留在普通选图界面。PvP参数5/20/5及搜索切磋资源可读，当前均不开放入场或发奖。

专用 C15/C16 准入复用正式副本实例。活动 DGN 将同一 MAP 重复到多个格子，部分 PvP 的 Boss 格没有实际地图；模块核对唯一 MAP、活动路径与原 `[clear map]` 目标后生成单战场路线。普通副本的门路校验继续独立执行。

剧情敌人取原 MAP；卡片在28建立活动实例后、29加载地图前通过1766/1767预登记，并使用当前实例预留的真实对象 key，从加载阶段启用客户端原生谋略战过渡。1766使用卡片编号，1767必须映射为EVT中的怪物资源编号，否则客户端查找失败，不生成友军。卡片使用普通生成品级0，等级95由客户端创建器固定；卡片不会混入普通29怪物行，也不额外注入 GM 支援兵。加载完成后才接受战斗事件。只有当前实例已有清图事实才能以46结算；友方全灭会阻止随后到达的敌方死亡报告产生胜利。

首次/重复奖励与关卡进度、成就、真实共享材料及非硬币奖励邮件共同提交。资源奖励列表中出现的怪物硬币同样合并直接入账，不重复放入邮件。同实例重复结算读取既有回执。活动不发普通角色或宠物经验、普通掉落、翻牌、幸运星及推荐地下城签到进度。

## 持久化与恢复

版本199增加账号卡册表 `account_monster_mock_battle` 和入场回执表 `account_monster_mock_battle_runs`。体力标记 `SupplyInitialized` 及日戳 `CoinMailDay` 保存在原卡册JSON，不再增加表或迁移。沿用旧日邮件日戳，当天已发每日邮件就不再直发100。卡册、资产和角色 revision 共用现有背包事务；入场体力、尝试号和回执共事务；胜利状态、费用余额、通关记录及非硬币奖励邮件共事务。提交前复核账号 owner、角色快照、卡册 revision 及活动开关版本。

失败或断线的局不会离线补发奖励；下一次入场将该账号未结算回执标为被替代。角色复制不复制战斗回执，账号卡册仍归原账号。重连、换角和服务重建从持久卡册恢复；SQL故障保留事务前资产，不将发送失败当成再次抽取或发奖的依据。

## 资源配套与验证

[资源导出工具](../../Tools/MonsterMockBattleResourcePatch/Program.cs)生成赛丽亚房间NPC引用和隐藏表的待导入文本：

```powershell
dotnet run --project Tools/MonsterMockBattleResourcePatch -- <原版Script.pvf> <新输出目录>
```

用PVF编辑器导入`map/common/(r)gate_seria.map`与`etc/hiddennpc.etc`：房间保留原版400001107并移除同位置、只有商店的400001112引用，同时从隐藏名单移除400001107。两处修改共同提供诺兰显示与原生游戏入口，具体步骤及独立修复脚本见[PVF适配说明](../资源/怪物模拟战PVF适配.md)。XUI、NPC定义、EVT及其日历等其他资源全部保留原版。浮点数采用可还原精度输出；工具不修改源PVF，不安装客户端补丁，也不设置整体资源hash门禁。

无资源规则、完整字节及存储回滚接入 `--selftest-core`。`--selftest-tcp monster-mock-battle` 覆盖真实卡册操作、共享材料、剧情/特殊关、对战入口拒绝、败北、活动关闭、晚期 SQL 入场回滚与服务重建换角恢复，并核对全部45关战场资源。公共副本、数据库及完整资源/TCP检查按[贡献指南](../../CONTRIBUTING.md#检查范围)执行。

静态消费者和 TCP 验证不代替客户端界面、怪物 AI 观感、资源导入后的 UI 布局及真实操作验收。未确认的状态 DWORD、保留区与回执附属字节仍按协议保留，不据此增加额外玩法。
