# 副本资源全量扫描与机制边界

目标为 S5A9 x86 客户端，资源目录见[开发环境](环境与配置.md)。[扫描入口](../../Server/DfoServer/GameWorld/Dungeons/DungeonResourceSurvey.cs)扫描 `dungeon/`、`map/`、`monster/`、`passiveobject/` 下的全部归档文件，包括目录未引用的脚本和非 token 文件。另遍历全部副本和地图目录，使用现有 Catalog 检查定义与房间结构。单条失败保留原因并继续其他条目。

按[固定资源目录](环境与配置.md#资源解析与固定目录)准备 PVF，从仓库根目录执行，将输出保存到自己的运行目录：

```sh
dotnet build ServerS5A9.sln -c Debug --nologo
dotnet Server/DfoServer/bin/Debug/net10.0/DfoServer.dll --scan-dungeons > '<扫描结果JSON>'
```

入口在仓储、实例锁和监听初始化之前返回，不打开玩家库、不发包。多余参数被拒绝，不回落到启动服务。扫描按压缩块读取，不将全部解压块留在在线缓存中；标签文本按字符串池ID共享，统计只保存计数。完整文件清单可能达到数百 MiB，直接流式输出JSON，避免额外构造整份字符串；结果仍包含全部文件并按路径排序。需为结果及目录解析准备空间，扫描结果属于运行资产，不提交 Git。

## 输出合同

| 字段 | 内容与边界 |
|---|---|
| `Scope`、`Evidence` | 扫描领域和证据类别 |
| `Files` | 逐文件路径、类型、长度、去重标签、原始 token 类型或读取错误；非 token 文件只检查读取长度 |
| `Dungeons` | 全部副本 ID/路径，完整解析成功时给出 maze 数与显式地图列表数；`GreedGrids`逐maze给出编码格式、已解码格数或具体Unsupported原因；定义失败时保留Error |
| `Maps` | 全部地图 ID/路径，成功时给出怪物/对象/buff 原始资源行数，否则保留拒绝原因 |
| `Tags` | 分领域原始标签及包含该标签的文件数；同文件重复标签只计一次 |

文件未读完时不发布局部标签；未知 token 类型保留原值。定义/房间的 `Error` 只表示当前解析器无法接受结构，不能据此断言匹配 PVF 损坏。Greed文本未知时单独返回 `GreedGrids` 的 `Format=unsupported`、null格数和原因，不阻断同副本其他maze或全量扫描；未发布部分格。AA..PP索引与线性消费边界见[资源合同](../资源/副本目录.md)，摘要不表示已批准通路。

文件数、标签数和解析成功/失败数随所用资源及解析器变化，以本次输出为准。完整定义的解析成功数量不表示可玩副本或已批准通路数量。

未知 Greed 编码按 maze 记录 Unsupported，保留其他可解析定义；其他结构与地图资格仍按各自规则验证，不能据此开放实例或路由。

已知的编码格数不足样例：Dungeon3624 maze0声明4×1、原文`BB`只有1格；Dungeon3654 maze0声明2×1、原文同为`BB`；Dungeon7130 maze5声明6×3、原文`AAAAAABBFFMM\r\n BBFFFFFFFFGG`只有12格。解析保留这些原文与尺寸，不补缺格，也不据此修改地图列表。

## 机制接入边界

普通资源已经能够描述显式 maze、起点/Boss 坐标及 map 引用，并保留固定怪物行、被动对象行与 buff 原值。[诊断进图](../协议/副本.md)的限定候选流程仍不代表正式战斗、真实死亡资格、通关、经验、掉落、拾取、结算或重复挑战。

| 结构或边界 | 尚需恢复 |
|---|---|
| `layered`（当前解析器不支持） | 分层布局、生成及真实传包消费者 |
| 随机或非显式地图、未知 map 类型/标记、greed 未支持编码或格数 | 实际生成、路径及准入规则；线性AA..PP索引不等于方向位 |
| size/坐标、重复坐标、起点/Boss 不匹配 | 坐标域与本版消费者；不删格子或夹取坐标来通过 |
| 非固定怪物行、重复/嵌套条件块 | 生成条件、事件时机、对象类型和读宽 |
| 被动对象空目录占位或引用未闭合 | 实际对象生成来源，不替换为任意普通对象 |
| 动作/脚本及其他标签 | 标签清单提供调查入口；每种机制分别恢复语义、协议并实机验收 |

通用引擎需按机制声明支持清单和拒绝原因，同机制资源在字段/资格闭合后复用。单人先完成，组队独立接入。事件绑定角色、任务 attempt、实例和 epoch；account generation / character revision 下同事务提交资产与进度。任务领奖和掉落分别保存防重复事实；发送失败不重跑提交。

## 验证

[C# 扫描测试](../../Server/DfoServer/SelfTests/DungeonResourceSurveyTests.cs)的短数据、残缺 token、无效字符串、未知标签/类型和不可变输出进入 `--selftest-core`，完整 `--selftest` 也包含这些检查。完整枚举、普通/拒绝条目并存及真实 Greed 摘要使用 `--selftest-tcp resource-survey` 显式运行，普通业务回归不重复扫描百万文件。扫描器或 PVF 格式、读取、缓存变化时补跑专项；文件和目录数量与当前归档独立枚举对比，不固定历史总数。CLI 参数由[命令测试](../../Server/DfoServer/SelfTests/CommandLineTests.cs)验证。完整包序、实例/事务及客户端验收随实际业务单独增加。
