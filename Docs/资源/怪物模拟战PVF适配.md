# 阿拉德谋略战 PVF 适配

适用于S5A9 / V31.0.24.0。以原版PVF为基础，修改赛丽亚房间的NPC引用，并将诺兰400001107从隐藏名单移除。XUI、NPC定义、EVT、日期、卡片、怪物及奖励均保留原版。服务端玩法见[模块说明](../模块/怪物模拟战.md)。

## 两处修改

打开`map/common/(r)gate_seria.map`的`[NPC]`段。原版在同一位置引用两名诺兰：

```text
400001107 `[right]` 608 168 0
400001112 `[right]` 608 168 0
```

保留400001107这整行，移除同位置的400001112整行，其余NPC与地图内容保持原样：

```text
400001107 `[right]` 608 168 0
```

原版400001107的NPC定义已经同时包含商店400000097和`[open monster mock battle] 1094`游戏入口。400001112只有商店；适配使用107的原版菜单。

若自己的资源已经只引用400001107，直接保留。若两名NPC的位置不同，先核对实际房间配置，不按上述同位置规则批量删除。

再打开`etc/hiddennpc.etc`，仅从`[hidden npc]`至`[/hidden npc]`之间删除整数`400001107`。其他隐藏NPC、`[npc visibility quest sequence]`及其任务号6356、5961均保留。107在原版隐藏名单中，仅修改房间引用仍不会显示诺兰；112不在该名单中，之前给112补菜单的方案无需取消隐藏，但该方案不属于本适配。

## 工具方式

[导出工具](../../Tools/MonsterMockBattleResourcePatch/Program.cs)使用服务端PvfLib读取原包，输出上述地图和隐藏表两份文本：

```powershell
dotnet run --project Tools/MonsterMockBattleResourcePatch -- <原版Script.pvf> <新输出目录>
```

将输出的`pvf/map/common/(r)gate_seria.map`和`pvf/etc/hiddennpc.etc`按原路径导入PVF编辑器后另存封包。客户端和服务端使用相同的配套PVF。工具不输出XUI、NPC定义或EVT修改，也不修改源归档。

交给其他agent时，可直接复制[独立修复目录](../../Tools/MonsterMockBattleResourcePatch/Portable/README.md)中的说明和脚本。独立脚本通过pvfUtility WebApi读取接收方已加载的封包，不依赖仓库、服务端DLL、本机目录或原始PVF文件副本；默认只预览，显式`-Apply -OutputPvf <新文件>`才导入并另存。

## 服务端配套

活动管理2532显示为“阿拉德谋略战”，默认开启；`off`关闭新召唤、新入场及商店购买，`on`开启，`auto`恢复默认开启。已有关闭状态在重启后保留。资源存在时无需创建独立设置文件即可开放玩法。

体力、每日硬币、券数量同步、获得画面星级和战斗怪物编号均由服务端处理，不通过改XUI实现。此前针对本地资源路径和测试控件的修改不属于本适配要求，不能据此认定官方UI错误。若此前已导入这些修改，应从自己保留的原版PVF重新开始，只导入上述两份文件。

原版特殊关卡绝对日历保持原样；服务端可选日期映射不修改客户端资源，不能把它当成客户端日历已更新。完成适配后验证诺兰可见、同时具有商店与游戏入口，以及原版召唤和卡册显示。
